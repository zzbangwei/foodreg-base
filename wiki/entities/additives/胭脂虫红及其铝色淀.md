# 胭脂虫红及其铝色淀(包括胭脂虫红,胭脂虫红铝色淀) (carmine cochineal,carmine cochine alaluminum lake)

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表A.1 |
| CNS号 | 08.145 |
| INS号 | 120 |
| 功能 | 着色剂 |

## 使用范围和最大使用量

| 食品类别 | 最大使用量 | 备注 |
|---------|-----------|------|
| 08.03.02 熏、烧、烤肉类（熏肉、叉烧肉、烤鸭、肉脯等） | 0.15 | 以 亚 硝 酸 钠 计 残 留 量 , ≤ 30mg/kg |
| 08.03.03 油炸肉类 | 0.15 | 以 亚 硝 酸 钠 计 残 留 量 , ≤ 30mg/kg |
| 08.03.04 西式火腿（熏烤、烟熏、蒸煮火腿）类 | 0.15 | 以 亚 硝 酸 钠 计 残 留 量 , ≤ 70mg/kg |
| 08.03.05 肉灌肠类 | 0.15 | 以 亚 硝 酸 钠 计 残 留 量 , ≤ 30mg/kg |
| 08.03.06 发酵肉制品类 | 0.15 | 以 亚 硝 酸 钠 计 残 留 量 , ≤ 30mg/kg |
| 08.03.08 肉罐头类 | 0.15 | 以 亚 硝 酸 钠 计 残 留 量 , ≤ 50mg/kg |
