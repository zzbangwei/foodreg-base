# 乳糖酶（β-半乳糖苷酶）(Lactase / β-Galactosidase) — 多来源

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | 乳糖酶（β-半乳糖苷酶） |
| **英文名称** | Lactase (β-Galactosidase) |

| **CMC分类** | 食品工业用酶制剂 |

## 各来源批准情况

乳糖酶作为食品工业用酶制剂已列入GB 2760，不同来源菌种先后获批。以下为2019-2026年间获批的新来源：

### 来源一：地衣芽孢杆菌（2020年第4号公告）

| 项目 | 内容 |
|------|------|
| **来源菌种** | 地衣芽孢杆菌 (*Bacillus licheniformis*) |
| **供体** | 两歧双歧杆菌 (*Bifidobacterium bifidum*) |
| **用途** | 乳及乳制品加工，水解乳糖 |

### 来源二：枯草芽孢杆菌（2022年第2号公告）

| 项目 | 内容 |
|------|------|
| **来源菌种** | 枯草芽孢杆菌 (*Bacillus subtilis*) |
| **供体** | 两歧双歧杆菌 (*Bifidobacterium bifidum*) |
| **用途** | 水解乳糖 |

### 其他早期来源（已列入GB 2760）

- **乳克鲁维酵母** (*Kluyveromyces lactis*)：2012年第15号公告
- **巴斯德毕赤酵母** (*Pichia pastoris*)：2013年第2号公告（供体：米曲霉）
- **两歧双歧杆菌** (*Bifidobacterium bifidum*)：2015年第1号公告
- **枯草芽孢杆菌**（另一来源）：2021年第2号公告（供体：两歧双歧杆菌）
