# 分支酶 (Branching Enzyme)

## 基本信息

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | 分支酶（α-1,4-葡聚糖分支酶） |
| **英文名称** | Branching Enzyme (1,4-α-Glucan Branching Enzyme) |
| **功能类别** | 食品工业用酶制剂 |
| **来源菌种** | 枯草芽孢杆菌 (*Bacillus subtilis*) |
| **供体** | — |
| **首次批准** | 2025年（2025年第7号公告） |
| **批准类型** | 食品工业用酶制剂新品种 |

## 用途

主要用于增加淀粉的分支度，如在淀粉加工生产麦芽糊精过程中使用。
