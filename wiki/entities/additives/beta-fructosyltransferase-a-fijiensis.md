# β-果糖基转移酶 (β-Fructosyltransferase)

## 基本信息

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | β-果糖基转移酶 |
| **英文名称** | β-Fructosyltransferase |
| **功能类别** | 食品工业用酶制剂 |
| **来源菌种** | *Aspergillus fijiensis* |
| **供体** | - |
| **首次批准** | 2022年5月11日（2022年第2号公告） |
| **批准类型** | 食品工业用酶制剂新品种 |

## 用途

主要用于将蔗糖转化为低聚果糖。

| 项目 | 内容 |

| **功能** | 催化蔗糖转化为低聚果糖 |
