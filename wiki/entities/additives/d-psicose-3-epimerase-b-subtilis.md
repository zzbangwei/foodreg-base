# D-阿洛酮糖-3-差向异构酶 (D-Psicose 3-Epimerase)

## 基本信息

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | D-阿洛酮糖-3-差向异构酶 |
| **英文名称** | D-Psicose 3-Epimerase (D-Allulose 3-Epimerase) |
| **功能类别** | 食品工业用酶制剂 |
| **来源菌种** | 枯草芽孢杆菌 (*Bacillus subtilis*) |
| **供体** | 瘤胃球菌 (*Ruminococcus* sp. 5_1_39B_FAA) |
| **首次批准** | 2024年（2024年公告） |
| **批准类型** | 食品工业用酶制剂新品种 |

## 用途

主要用于催化D-果糖的差向异构化制得D-阿洛酮糖。D-阿洛酮糖是一种低热量稀有糖，作为新食品原料已于2025年第4号公告获批，其中酶转化法工艺即使用本酶制剂。
