# 丝氨酸蛋白酶 (Serine Protease) — 地衣芽孢杆菌来源

## 基本信息

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | 丝氨酸蛋白酶 |
| **英文名称** | Serine Protease |
| **功能类别** | 食品工业用酶制剂 |
| **来源菌种** | 地衣芽孢杆菌 (*Bacillus licheniformis*) |
| **供体** | - |
| **首次批准** | 2023年10月（2023年第8号公告） |
| **批准类型** | 食品工业用酶制剂新品种 |
| **CMC分类** | 酶制剂 |

## 用途

该物质作为食品工业用酶制剂，主要用于催化胰凝乳蛋白的水解。

## 国际批准情况

- **美国FDA**：允许作为食品工业用酶制剂使用
- **法国食品安全局（ANSES）**：允许作为食品工业用酶制剂使用
- **丹麦兽医和食品局**：允许作为食品工业用酶制剂使用
- **澳大利亚和新西兰食品标准局（FSANZ）**：允许作为食品工业用酶制剂使用
