# β-葡聚糖酶 (β-Glucanase)

## 基本信息

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | β-葡聚糖酶 |
| **英文名称** | β-Glucanase |
| **功能类别** | 食品工业用酶制剂 |
| **来源菌种** | 枯草芽孢杆菌 (*Bacillus subtilis*) |
| **供体** | — |
| **首次批准** | 2022年5月11日（2022年第2号公告） |
| **批准类型** | 食品工业用酶制剂新品种 |

## 用途

主要用于催化β-葡聚糖的水解。

## 备注

β-葡聚糖酶作为食品工业用酶制剂此前已有其他来源列入GB 2760。本次公告为枯草芽孢杆菌来源的新品种。
