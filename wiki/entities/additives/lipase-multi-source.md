# 脂肪酶 (Lipase) — 多来源

| 项目 | 内容 |

| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | 脂肪酶 |

## 各来源批准情况

脂肪酶作为食品工业用酶制剂已列入GB 2760，不同来源菌种先后获批。以下为2019-2026年间获批的新来源：

### 来源一：黑曲霉（2020年第4号公告）

| 项目 | 内容 |
|------|------|
| **来源菌种** | 黑曲霉 (*Aspergillus niger*) |
| **供体** | 黄色镰刀菌 (*Fusarium culmorum*) |
| **用途** | 烘焙食品等，增加生面团发酵稳定性 |

### 来源二：多形汉逊酵母（2020年第4号公告）

| 项目 | 内容 |
|------|------|
| **来源菌种** | 多形汉逊酵母 (*Hansenula polymorpha*) |
| **供体** | 异孢镰刀菌 (*Fusarium hetreosporum*) |
| **用途** | 油脂加工 |

### 来源三：李氏木霉（2022年第1号公告）

| 项目 | 内容 |
|------|------|
| **来源菌种** | 李氏木霉 (*Trichoderma reesei*) |
| **供体** | 尖孢镰刀菌 (*Fusarium oxysporum*) |
| **用途** | 催化脂类物质水解 |

### 其他早期来源（已列入GB 2760）

- **柱晶假丝酵母** (*Candida cylindracea*)：2012年第6号公告
- **卷枝毛霉** (*Mucor circinelloides*)：2018年第8号公告
