# 木聚糖酶 (Xylanase) — 李氏木霉来源

## 基本信息

| 项目 | 内容 |
|------|------|
| **所属标准** | GB 2760-2024 表C.2 |
| **中文名称** | 木聚糖酶 |
| **英文名称** | Xylanase |
| **功能类别** | 食品工业用酶制剂 |
| **来源菌种** | 李氏木霉 (*Trichoderma reesei*) |
| **供体** | Talaromyces leycettanus |
| **首次批准** | 2020年6月2日（2020年第4号公告） |
| **批准类型** | 食品工业用酶制剂新品种 |

## 用途

主要用于谷物加工，分离谷物淀粉、谷物蛋白和谷物纤维。

## 备注

木聚糖酶作为食品工业用酶制剂已列入《食品安全国家标准 食品添加剂使用标准》（GB 2760），允许用于多种食品加工工艺。除李氏木霉来源外，后续公告新增了其他生产菌来源的木聚糖酶品种（2021年第9号：李氏木霉新供体；2025年第4号：新生产菌来源，用于淀粉加工和酒精发酵；2025年第3号：新生产菌来源，用于面包加工）。
