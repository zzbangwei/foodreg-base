# 大豆及其制品（豆）

## 概述

大豆及其制品是 GB 7718-2011 规定的八大类推荐标识致敏物质第6类。记忆口诀"鱼果麦虾，蛋奶豆花"中的"豆"。现行标准（GB 7718-2011）要求为推荐性标识，GB 7718-2025将于2027年3月16日升级为强制性标识。

## 基本信息

| 项目 | 内容 |
|------|------|
| 过敏原类别 | 大豆及其制品 |
| 记忆口诀 | 豆 |
| 法规依据 | GB 7718-2011 第4.4.3条、问答（修订版）第五十条 |
| 标识性质 | 推荐性标识（过渡期）；2027.3.16起强制 |
| 涵盖品种 | 黄豆、黑豆、青豆、毛豆（未成熟大豆） |

## 常见食品来源

豆浆、豆奶、豆腐、豆花、豆腐干、豆皮、腐竹、腐皮、酱油（生抽/老抽）、豆瓣酱、黄豆酱、豆豉、面畨、豆腐乳、纳豆、味噌、天贝、大豆油、大豆粉、素肉/人造肉、豆奶粉、豆芽、大豆冰淇淋、豆酸奶、能量棒

## 配料表别名/隐藏名称

| 别名类别 | 具体名称 |

| 豆类品种 | 黄豆、毛豆、黑豆、青豆 |

| 油/脂类 | 植物油（可能为大豆油）、色拉油（可能为大豆油）、植物起酥油、植物脂肪 |
| 发酵/调味类 | 酱油、生抽、老抽、豆瓣酱、黄豆酱、豆豉、面畨、味噌、纳豆 |
| 磷脂/添加剂类 | 大豆卵磷脂、磷脂（大豆来源）、黄原胶（可能为大豆发酵来源）、维生素E（大豆来源） |

| 香料类 | 天然香料（可能含大豆衍生物） |

## 豁免情况

| 可豁免配料 | 说明 |
|-----------|------|
| 精炼大豆油 | 精炼过程去除致敏蛋白质 |
| 大豆磷脂 | 正常生产不含致敏蛋白质 |
| 维生素E（大豆来源） | 正常生产不含致敏蛋白质 |
| 植物甾醇及酯类 | 正常生产不含致敏蛋白质 |
| 黄原胶 | 发酵生产，正常生产不含致敏蛋白质 |

## 法规依据

- GB 7718-2011 第4.4.3条：八大类致敏物质推荐性标识要求
- GB 7718-2011 问答（修订版）第五十条：致敏物质标识具体说明
- GB 7718-2025：2027年3月16日实施，过敏原标识升级为强制性
