# 蛋类及其制品（蛋）

## 概述

蛋类及其制品是 GB 7718-2011 规定的八大类推荐标识致敏物质第4类。记忆口诀"鱼果麦虾，蛋奶豆花"中的"蛋"。现行标准（GB 7718-2011）要求为推荐性标识，GB 7718-2025将于2027年3月16日升级为强制性标识。

## 基本信息

| 项目 | 内容 |
|------|------|
| 过敏原类别 | 蛋类及其制品 |
| 记忆口诀 | 蛋 |
| 法规依据 | GB 7718-2011 第4.4.3条、问答（修订版）第五十条 |
| 标识性质 | 推荐性标识（过渡期）；2027.3.16起强制 |
| 涵盖品种 | 鸡蛋、鸭蛋、鹅蛋、鹌鹑蛋等禽蛋 |

## 常见食品来源

鲜蛋、皮蛋、咸蛋、蛋粉（全蛋粉、蛋黄粉、蛋白粉）、蛋液、蛋黄酱、沙拉酱、塔塔酱、面包、蛋糕、饼干、糕点、蛋奶酒、冰淇淋、蛋奶冻、布丁、意大利面（鸡蛋面）、蛋白霜、棉花糖、牛轧糖、肉丸、香肠、煎饼、华夫饼

## 配料表别名/隐藏名称

| 别名类别 | 具体名称 |
|---------|---------|
| 蛋白类 | 白蛋白/清蛋白（Albumin/Albumen）、卵清蛋白（Ovalbumin）、球蛋白（Globulin） |
| 卵磷/酶类 | 卵磷脂（Lecithin，可能来自蛋黄）、溶菌酶（Lysozyme，E1105） |
| 蛋粉/蛋液类 | 蛋粉/鸡蛋粉（Powdered egg）、蛋液（Egg solids） |
| 蛋黄蛋白类 | 蛋黄球蛋白（Livetin）、卵黄蛋白（Ovovitellin）、卵黏蛋白（Ovomucin） |
| 功能性成分类 | 乳化剂（可能含蛋）、黏合剂/凝固剂（可能含蛋）、脂肪替代品（Simplesse，蛋蛋白制品） |
| 隐含含蛋类 | 鱼糜/蟹味棒（可能含蛋清） |

## 豁免情况

无明确豁免项。蛋类过敏原需在配料表中使用易辨识的名称标示。

## 法规依据

- GB 7718-2011 第4.4.3条：八大类致敏物质推荐性标识要求
- GB 7718-2011 问答（修订版）第五十条：致敏物质标识具体说明
- GB 7718-2025：2027年3月16日实施，过敏原标识升级为强制性
