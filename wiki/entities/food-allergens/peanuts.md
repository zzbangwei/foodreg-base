# 花生及其制品（花）

## 概述

花生及其制品是 GB 7718-2011 规定的八大类推荐标识致敏物质第5类。记忆口诀"鱼果麦虾，蛋奶豆花"中的"花"。花生属于豆科植物，非树坚果，但因过敏风险高单独列为一类。现行标准（GB 7718-2011）要求为推荐性标识，GB 7718-2025将于2027年3月16日升级为强制性标识。

## 基本信息

| 项目 | 内容 |
|------|------|
| 过敏原类别 | 花生及其制品 |
| 记忆口诀 | 花 |
| 法规依据 | GB 7718-2011 第4.4.3条、问答（修订版）第五十条 |
| 标识性质 | 推荐性标识（过渡期）；2027.3.16起强制 |
| 涵盖品种 | 花生（落花生、长生果）、花生仁、花生粉、花生蛋白 |

## 常见食品来源

花生酱、花生油、花生碎、混合坚果、花生巧克力、牛轧糖、能量棒、谷物棒、麦片、沙拉酱、沙茶酱、花生芝麻酱、火锅蘸料、糖果、冰淇淋、谷物面包、宠物食品

## 配料表别名/隐藏名称

| 别名类别 | 具体名称 |
|---------|---------|
| 中文学名 | 落花生、长生果 |
| 英文/拉丁名 | 花生油（Arachis oil）、Arachis / Arachis hypogaea（拉丁学名） |
| 蛋白类 | 花生蛋白、水解花生蛋白、水解植物蛋白-HVP（花生来源） |
| 坚果替代类 | 人造坚果（Artificial nuts）、Nu-Nuts调味坚果、Mandelonas（浸泡杏仁香料的花生）、啤酒坚果（Beer nuts） |
| 混合坚果类 | 坚果酱（可能含花生）、坚果碎/坚果片（混合坚果中常见） |
| 香料类 | 天然香料/人工香料（可能含花生衍生物） |

## 豁免情况

| 可豁免配料 | 说明 |
|-----------|------|
| 精炼花生油 | 深度精炼后蛋白质已被去除 |

> 冷榨/压榨花生油不在豁免范围。

## 法规依据

- GB 7718-2011 问答（修订版）第五十条：致敏物质标识具体说明
- GB 7718-2025：2027年3月16日实施，过敏原标识升级为强制性
