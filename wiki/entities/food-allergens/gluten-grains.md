# 含有麸质的谷物及其制品（麦）

## 概述

含有麸质的谷物及其制品是 GB 7718-2011 规定的八大类推荐标识致敏物质第1类。记忆口诀"鱼果麦虾，蛋奶豆花"中的"麦"。现行标准（GB 7718-2011）要求为推荐性标识，GB 7718-2025将于2027年3月16日升级为强制性标识。

## 基本信息

| 项目 | 内容 |
|------|------|
| 过敏原类别 | 含有麸质的谷物及其制品 |
| 记忆口诀 | 麦 |
| 法规依据 | GB 7718-2011 第4.4.3条、问答（修订版）第五十条 |
| 标识性质 | 推荐性标识（过渡期）；2027.3.16起强制 |
| 涵盖品种 | 小麦、黑麦、大麦、燕麦、斯佩耳特小麦、卡姆小麦、硬质小麦（杜兰小麦）及其杂交品系 |

## 常见食品来源

面包、面条、馒头、饺子、方便面、饼干、蛋糕、月饼、啤酒、酱油、醋、麦片、面筋、烤麸、素鸡、素鸭、通心粉、煎饼、春卷皮、汉堡包、甜甜圈、面包糠、麦芽饮品、麦芽糊精

## 豁免情况

以下经深度加工的配料可免于标示：

| 可豁免配料 | 说明 |
|-----------|------|
| 淀粉（谷物来源） | 正常生产不含致敏蛋白质 |
| 糊精（包括麦芽糊精） | 正常生产不含致敏蛋白质 |
| 葡萄糖浆 | 正常生产不含致敏蛋白质 |
| 谷物来源的精炼植物油 | 精炼工艺去除蛋白质成分 |
| 食用酒精、蒸馏酒 | 蒸馏过程去除致敏蛋白质 |

## 法规依据

- GB 7718-2011 第4.4.3条：八大类致敏物质推荐性标识要求
- GB 7718-2011 问答（修订版）第五十条：致敏物质标识具体说明
- GB 7718-2025：2027年3月16日实施，过敏原标识升级为强制性
