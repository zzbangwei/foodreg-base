# 玉米低聚肽粉

## 概述

玉米低聚肽粉（Corn oligopeptides powder）是以玉米蛋白粉为原料，经蛋白酶酶解制成的寡肽混合物。我国于2010年首次批准为新资源食品，后于2013年按普通食品管理。

> **当前管理状态：普通食品原料**（不再作为新资源/新食品原料管理）
> 
> 依据：2013年第3号公告第二条 — 以可食用的植物蛋白质为原料，经GB2760规定允许使用的食品用酶制剂酶解制成的物质作为普通食品管理。
> 
> 2023年第4号公告《"三新食品"目录》再次确认：按普通食品管理。
> 
> 广东省市场监督管理局答复（2025-03-24）：标签无需标注不适宜人群和食用限量，按GB 7718常规要求即可。食品安全指标参照谷物及其制品国标。详见 [[玉米低聚肽粉的法规分类及标签标识要求]]。

## 质量要求

| 指标 | 要求 |
|------|------|
| 性状 | 黄色或棕黄色粉末 |
| 蛋白质（以干基计） | ≥80.0% |
| 低聚肽（以干基计） | ≥75.0% |
| AY（丙氨酸-酪氨酸） | ≥0.6% |
| 相对分子质量小于1000的蛋白质水解物所占比例 | ≥90.0% |
| 水分 | ≤7.0% |
| 灰分 | ≤8.0% |

注：AY为Ala-Tyr的缩写，即丙氨酸-酪氨酸，相对分子质量为252.12。

## 禁忌人群

婴幼儿不宜食用。标签、说明书中应当标注不适宜人群和食用限量。
