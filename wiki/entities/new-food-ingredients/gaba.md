# γ-氨基丁酸

## 概述

γ-氨基丁酸（Gamma aminobutyric acid，GABA）是以L-谷氨酸钠为原料经希氏乳杆菌发酵制得的非蛋白质氨基酸。我国于2009年首次批准为新资源食品，广泛用于饮料、糖果、焙烤食品等。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | γ-氨基丁酸 |
| 英文名称 | Gamma aminobutyric acid (GABA) |
| 基本信息 | 来源：L-谷氨酸钠；结构式：NH₂CH₂CH₂CH₂COOH；分子式：C₄H₉NO₂；分子量：103.12 |
| 生产工艺简述 | 以L-谷氨酸钠为原料经希氏乳杆菌（*Lactobacillus hilgardii*）发酵、加热杀菌、冷却、活性炭处理、过滤、加入调配辅料（淀粉）、喷雾干燥等步骤生产而成。 |
| 食用量 | ≤500毫克/天 |
