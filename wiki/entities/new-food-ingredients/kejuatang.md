# 壳寡糖

## 概述

壳寡糖（Chitosan Oligosaccharide），以壳聚糖为原料经酶解制成，由2-10个聚合度的寡聚氨基葡萄糖组成。我国于2014年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 壳寡糖 |
| 英文名称 | Chitosan Oligosaccharide |
| 来源 | 壳聚糖 |
| 分子式 | (C₆H₁₁O₄N)ₙ，n为2-10 |
| 生产工艺 | 以壳聚糖为原料，经木瓜蛋白酶（或木瓜蛋白酶和纤维素酶）酶解、过滤、喷雾干燥等工艺制成 |
| 推荐食用量 | ≤0.5 克/天 |

| 指标 | 要求 |

使用范围不包括婴幼儿食品。
