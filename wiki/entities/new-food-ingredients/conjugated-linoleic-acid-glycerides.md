# 共轭亚油酸甘油酯

## 概述

共轭亚油酸甘油酯（Conjugated Linoleic Acid Glycerides）是以红花籽油为原料，经共轭化后与甘油酯化制得的甘油三酯。我国于2009年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 共轭亚油酸甘油酯 |
| 英文名称 | Conjugated Linoleic Acid Glycerides |
| 主要成分 | 共轭亚油酸甘油三酯 |
| 基本信息 | 来源：红花籽油；R是共轭亚油酸C18:2 9c,11t或10t,12c异构体 |
| 生产工艺简述 | 以食品级的红花籽油为原料，通过共轭化反应将其中的亚油酸转化成共轭亚油酸，然后以食品级脂肪酶为催化剂，将共轭亚油酸脂肪酸与甘油进行酯化，生成共轭亚油酸甘油酯。 |
| 食用量 | < 6克/天 |
