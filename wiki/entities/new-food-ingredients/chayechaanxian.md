# 茶叶茶氨酸

## 概述

茶叶茶氨酸（Theanine），是以茶叶为原料经提取、过滤、浓缩等工艺制成的天然氨基酸，是茶叶中特有的游离氨基酸。我国于2014年批准为新食品原料，食用量≤0.4克/天。同公告将海藻糖按普通食品管理。

| 项目 | 内容 |
|------|------|
| 中文名称 | 茶叶茶氨酸 |
| 英文名称 | Theanine |

| 分子量 | 174.2 |
| 生产工艺 | 以茶叶为原料，经提取、过滤、浓缩等工艺制成 |
| 推荐食用量 | ≤0.4 克/天 |
