# 地龙蛋白

## 概述

地龙蛋白（Earthworm Protein）是以赤子爱胜蚓（*Eisenia foetida*）为原料，经水解自溶制成的蛋白质产品。我国于2009年首次批准为新资源食品。产品中不得检出蚓激酶。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 地龙蛋白 |
| 英文名称 | Earthworm Protein |
| 基本信息 | 来源：赤子爱胜蚓（*Eisenia foetida* Savigny） |
| 生产工艺简述 | 以地龙（蚯蚓）经挑选洗涤、水解自溶、离心分离、微滤、喷雾干燥、包装等工艺制成。 |
| 食用量 | ≤10克/天 |

## 批准历程

| 公告 | 日期 | 发布机构 | 食用量 | 说明 |
|------|------|---------|--------|------|
| [[weish-2009-18-chayeziyou-7-zhong|2009年第18号]] | 2009-12-22 | 卫生部 | ≤10克/天 | **首次批准**为新资源食品 |

## 质量要求

| 指标 | 要求 |
|------|------|
| 性状 | 浅黄色粉末 |
| 蛋白质含量 | ≥65% |
| 水分 | ≤8.0% |
| 灰分 | ≤9.0% |
| 蚓激酶 | 不得检出 |

## 禁忌人群

婴幼儿、少年儿童、孕产妇、过敏体质者不宜食用。在产品的标签、说明书中应标注"婴幼儿、少年儿童、孕产妇、过敏体质者不宜食用"。
