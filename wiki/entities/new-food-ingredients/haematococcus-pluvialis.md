# 雨生红球藻

## 概述

雨生红球藻（*Haematococcus pluvialis*）为绿藻门红球藻属微藻，富含虾青素。我国于2010年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 雨生红球藻 |
| 拉丁名称 | *Haematococcus pluvialis* |
| 基本信息 | 种属：绿藻门、团藻目、红球藻科、红球藻属 |
| 生产工艺简述 | 选育、接种、人工培养、采收、脱水、干燥等工艺制成。 |
| 食用量 | ≤0.8克/天 |

## 批准历程

| 公告 | 日期 | 发布机构 | 食用量 | 使用范围 | 说明 |
|------|------|---------|--------|---------|------|
| [[weish-2010-17-yushenghongqiuzao-egcg|2010年第17号]] | 2010-10-29 | 卫生部 | ≤0.8克/天 | 不包括婴幼儿食品 | **首次批准**为新资源食品 |

## 质量要求

| 指标 | 要求 |
|------|------|
| 性状 | 红褐色粉末 |
| 蛋白质 | ≥15% |
| 总虾青素（以全反式虾青素计） | ≥1.5% |
| 全反式虾青素 | ≥0.8% |
| 水分 | ≤10% |
| 灰分 | ≤15% |
