# L-阿拉伯糖

## 概述

L-阿拉伯糖（L-Arabinose），2008年5月26日经卫生部公告（[[weish-2008-12-7-new-resource-foods|2008年第12号]]）批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | L-阿拉伯糖 |
| 英文名称 | L-Arabinose |
| 来源 | 玉米芯、玉米皮等禾本科植物纤维 |
| 分子式 | C₅H₁₀O₅ |
| 分子量 | 150.13 |
| 批准日期 | 2008-05-26 |

## 生产与使用

- **生产工艺**：以玉米芯、玉米皮等禾本科植物纤维为原料，经稀酸水解、脱色、脱酸、生物发酵、分离净化、结晶、干燥得到。
- **使用范围**：各类食品，**不包括婴幼儿食品**
- **性状**：白色结晶粉末

## 质量规格

| 指标 | 要求 |
|------|------|
| L-阿拉伯糖含量 | ≥99.0% |
| 水分 | ≤1.0% |
| 灰分 | ≤0.1% |
| 熔点 | 154-158℃ |
| 比旋光度 [α]²⁰ᴅ（C=5，H₂O，24h） | +100º～+104º |

## 批准背景

属于 [[weish-2008-12-7-new-resource-foods|卫生部2008年第12号公告]] 批准的7种新资源食品之一。L-阿拉伯糖具有蔗糖酶抑制特性，常作为功能性甜味剂使用。
