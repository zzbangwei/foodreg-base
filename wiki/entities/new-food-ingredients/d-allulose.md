# D-阿洛酮糖

## 概述

D-阿洛酮糖是一种六碳酮糖，少量天然存在于无花果、猕猴桃、小麦等食品中，能量系数约为1.67 kJ/g。本产品通过微生物发酵法或酶转化法生产。我国于2025年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | D-阿洛酮糖 |
| 类型 | 六碳酮糖 |
| 能量系数 | 约1.67 kJ/g |
| 自然存在 | 少量存在于无花果、猕猴桃、小麦等食品中 |
| 生产工艺 | 微生物发酵法：以葡萄糖或蔗糖为原料，经大肠杆菌AS10（*Escherichia coli* AS10）发酵、提纯、结晶、干燥；酶转化法：以果糖为原料，经D-阿洛酮糖-3-差向异构酶催化转化，再经脱色、分离、提纯、结晶、干燥 |
| 纯度 | ≥98 g/100g |
| 推荐食用量 | ≤20克/天 |
| 不适宜人群 | 婴幼儿、孕妇和哺乳期妇女 |
