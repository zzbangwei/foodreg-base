# 黑果腺肋花楸果

## 概述

黑果腺肋花楸果，经公告[[weish-2018-10-黑果腺肋花楸果等2种新食品原料|2018年第10号]]批准为新资源食品/新食品原料。

## 基本信息

### 1. 黑果腺肋花楸果

| 项目 | 内容 |
|------|------|
| **中文名称** | 黑果腺肋花楸果 |
| **英文名称** | Black chokeberry |
| **拉丁名称** | *Aronia melanocarpa* (Michx.) Ell. |
| **基本信息** | 种属：蔷薇科、腺肋花楸属。食用部位：果实。黑果腺肋花楸是一种从国外引进的蔷薇科、腺肋花楸属灌木浆果果树，其果实在欧亚及北美等国家具有较长食用历史，主要被用来生产着色剂、糖浆、果汁、果酱及果酒等。我国部分地区自2005年开始引种黑果腺肋花楸，目前已在辽宁、江苏、浙江、吉林等多个省区内种植。 |
| **不适宜人群** | 婴幼儿、孕妇及哺乳期妇女 |
| **推荐食用量** | ≤10克/天（以鲜品计） |
| **其他需要说明的情况** | 1. 婴幼儿、孕妇及哺乳期妇女不宜食用，标签及说明书中应当标注不适宜人群。<br>2. 食品安全指标按照食品安全国家标准中有关水果的规定执行。 |
