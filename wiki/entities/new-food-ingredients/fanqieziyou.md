# 番茄籽油

## 概述

番茄籽油（Tomato Seed Oil），以番茄籽为原料经萃取、精练等工艺制成，富含亚油酸（≥50%）。我国于2014年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 番茄籽油 |
| 英文名称 | Tomato Seed Oil |
| 来源 | 番茄籽 |
| 生产工艺 | 以番茄籽为原料，经萃取、精练等工艺而制成 |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 淡黄色到橙色油状液体 |
| 亚油酸 (C18:2) | ≥50%（占总脂肪酸含量比） |
| 油酸 (C18:1) | ≥19%（占总脂肪酸含量比） |
| 棕榈酸 (C16:0) | ≤13%（占总脂肪酸含量比） |

> 食品安全指标按照我国现行食品安全国家标准中植物油脂的规定执行（2023年第4号修订）。
