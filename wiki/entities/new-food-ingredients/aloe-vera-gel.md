# 库拉索芦荟凝胶

## 概述

库拉索芦荟凝胶（Aloe Vera Gel），2008年5月26日经卫生部公告（[[weish-2008-12-7-new-resource-foods|2008年第12号]]）批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 库拉索芦荟凝胶 |
| 拉丁名称 | Aloe Vera Gel |
| 来源 | 库拉索芦荟叶片 |
| 食用部位 | 凝胶肉 |
| 批准日期 | 2008-05-26 |

## 生产与使用

- **生产工艺**：以库拉索芦荟叶片为原料，经沥醌清洗、去皮、漂烫、杀菌等步骤制成。
- **使用范围**：各类食品
- **性状**：无色透明至乳白色凝胶

## 食用量与禁忌

| 项目 | 内容 |
|------|------|
| 食用量 | ≤30克/天 |
| 不适宜人群 | **孕妇、婴幼儿** |

## 质量规格

| 指标 | 要求 |
|------|------|
| 芦荟苷（mg/kg） | ≤7.0 |
| 多糖（mg/kg） | ≥200.0 |
| O-乙酰基（mg/kg） | ≥175.0 |
| pH | 4.0-5.5 |

## 批准背景

属于 [[weish-2008-12-7-new-resource-foods|卫生部2008年第12号公告]] 批准的7种新资源食品之一。
