# 植物甾醇

## 概述

植物甾醇（Plant sterol），2010年3月9日经卫生部公告（[[weish-2010-3-dha-7-zhong|2010年第3号]]）首次批准为新资源食品。2026年5月27日，国家卫健委通过[[weish-2026-5-牡丹籽油等7种新食品原料|2026年第5号]]公告对其进行修订，增加新的生产工艺和性状，并调整塔罗油来源产品的组成比例。

植物甾醇是植物中存在的一类天然化合物，主要存在于植物油、坚果、谷物等食品中。在美国被作为"一般认为安全的物质（GRAS）"管理；欧盟、澳大利亚和新西兰批准其为新食品原料。

## 生产工艺

### 2010年原始工艺
利用大豆油等植物油馏分或者塔罗油为原料，通过皂化、萃取、结晶等工艺生产制得。

### 2026年新增工艺
- **工艺一**（原有）：以大豆油、菜籽油、玉米油、葵花籽油、塔罗油为原料，经皂化、萃取、结晶等工艺制成
- **工艺二**（新增）：以大豆油、菜籽油、玉米油、葵花籽油为原料，经酯化、蒸馏、结晶等工艺制成

## 性状

- **2010年**：白色粉末或颗粒
- **2026年**：增加新性状（详见2026年第5号公告）

## 使用范围

不包括婴幼儿食品。

## 食用量

≤2.4 克/天

## 禁忌人群

婴幼儿不宜食用。

## 质量规格

### 2010年第3号公告（原始规格）

| 指标 | 要求 |
|------|------|
| 性状 | 白色粉末或颗粒 |
| 植物甾醇 | ≥90% |
| β-谷甾醇 | ≥30.0% |
| 菜油甾醇 | ≥15.0% |
| 豆甾醇 | ≥12.0% |

### 2026年第5号公告（修订后）

| 指标 | 大豆油等植物油来源 | 塔罗油来源 |
|------|-------------------|------------|
| 性状 | 白色至乳白色粉末或颗粒 | 白色至乳白色粉末或颗粒 |
| 植物甾醇 | ≥90.0% | ≥90.0% |
| β-谷甾醇 | ≥30.0% | ≥70.0% |
| 菜油甾醇 | ≥15.0% | ≥4.0% |
| 豆甾醇 | ≥12.0% | ≥0.4% |
| 推荐食用量 | ≤2.4 克/天 | ≤2.4 克/天 |

**食品安全指标（2026年第5号公告新增）**：
- 铅（Pb） ≤0.1 mg/kg
- 总砷（As） ≤0.1 mg/kg
- 苯并[a]芘 ≤10.0 μg/kg

> **注**：2026年第5号公告调整了塔罗油来源植物甾醇的组成比例，基于新数据论证重新公告。新增酯化/蒸馏/结晶工艺路线的产品性状和质量要求详见公告原文。原卫生部2010年第3号公告植物甾醇相关信息作废。
