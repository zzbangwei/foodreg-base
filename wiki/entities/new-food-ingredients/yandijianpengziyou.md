# 盐地碱蓬籽油

## 概述

盐地碱蓬籽油（*Suaeda salsa* seed oil），来源于藜科碱蓬属盐地碱蓬（*Suaeda salsa* (L.) pall）种子，经萃取、脱色、过滤等工艺制成。富含亚油酸（≥50%）。我国于2013年批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 盐地碱蓬籽油 |
| 拉丁名称 | *Suaeda salsa* seed Oil |
| 来源 | 藜科碱蓬属盐地碱蓬（*Suaeda salsa* (L.) pall）种子 |
| 生产工艺 | 以盐地碱蓬种子为原料，经萃取、脱色、过滤等工艺而制成 |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 淡黄色至金黄色透明油状液体 |
| 亚油酸 (C18:2) | ≥50%（占总脂肪酸含量比） |
| 油酸 (C18:1) | ≥10%（占总脂肪酸含量比） |
| 亚麻酸 (C18:3) | ≥5%（占总脂肪酸含量比） |

## 禁忌人群

使用范围不包括婴幼儿食品。
