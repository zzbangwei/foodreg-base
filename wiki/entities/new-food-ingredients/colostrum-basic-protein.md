# 初乳碱性蛋白

## 概述

初乳碱性蛋白（Colostrum Basic Protein，CBP）是以牛初乳为原料提取的小分子活性蛋白，分子量1~30 kD。我国于2009年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 初乳碱性蛋白 |
| 英文名称 | Colostrum Basic Protein (CBP) |
| 基本信息 | 来源：牛初乳；分子量：1~30 kD（千道尔顿），属于小分子活性蛋白 |
| 生产工艺简述 | 以牛初乳为原料，经杀菌、脱脂、离心分离、去除酪蛋白、α-乳白蛋白、β-乳球蛋白，微滤、超滤、冷冻干燥等工艺而制成。 |
| 食用量 | ≤100毫克/天 |
