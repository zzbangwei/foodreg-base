# 奇亚籽

## 概述

奇亚籽，经公告[[weish-2014-10-塔格糖等6种新食品原料|2014年第10号]]批准为新资源食品/新食品原料。

## 基本信息

### 2. 奇亚籽

| 项目 | 内容 |
|------|------|
| **中文名称** | 奇亚籽 |
| **英文名称** | Chia seed |
| **基本信息** | 来源：唇形科鼠尾草属芡欧鼠尾草（拉丁学名：*Salvia hispanica* L.）；食用部位：种子 |
| **使用范围** | 不包括婴幼儿食品 |
| **其他需要说明的情况** | 食品安全指标按照我国现行食品安全国家标准中坚果与籽类的规定执行（由2023年第4号公告修订） |
