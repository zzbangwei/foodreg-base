# 透明质酸钠（食品原料）

## 概述

透明质酸钠（Sodium Hyaluronate）是一种高分子粘多糖，广泛存在于动物组织中。我国自2008年起分三个阶段批准其使用：最初仅限保健食品原料，2020年扩大至普通食品，2025年新增提取法工艺路线。目前共有两种获批生产工艺：发酵法和提取法。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 透明质酸钠 |
| 英文名称 | Sodium Hyaluronate |
| 分子式（发酵法） | (C₁₄H₂₀NNaO₁₁)ₙ，n为200-10000 |
| 分子量（发酵法） | 8.02×10⁴ — 4.01×10⁶ |
| 基本结构 | 由D-葡萄糖醛酸和N-乙酰氨基葡萄糖双糖单元重复连接而成的直链高分子粘多糖 |

## 质量规格

### 发酵法（2008年第12号 / 2020年第9号）

| 指标 | 2008年第12号 | 2020年第9号 |
|------|-------------|-------------|
| 性状 | 白色颗粒或粉末 | 白色至类白色粉末或颗粒 |
| 透明质酸钠含量 | ≥87.0% | ≥90.0% |
| 水分 | ≤10.0% | — |
| pH | 6.0-8.0 | — |
| 灰分 | ≤13.0% | — |

### 提取法（2025年第4号）

| 指标 | 要求 |
|------|------|
| 透明质酸钠含量 | ≥60 g/100g |
| 主要成分 | 透明质酸钠、硫酸软骨素、胶原蛋白等 |

## 禁忌人群

婴幼儿、孕妇及哺乳期妇女不宜食用。标签及说明书应当标注不适宜人群和推荐食用量（≤200毫克/天或≤300毫克/天，视工艺而定）。

## 国际使用情况

以提取法生产的透明质酸钠在美国被作为"一般认为安全的物质（GRAS）"管理，可用于饮料、乳制品、糖果等食品；欧盟批准其为新食品原料。发酵法产品在多个国家和地区已批准使用。
