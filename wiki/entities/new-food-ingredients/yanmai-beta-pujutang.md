# 燕麦β-葡聚糖

## 概述

燕麦β-葡聚糖（Oat β-glucan），以燕麦麸为原料经水解、提取等工艺制成的β-1,3-/1,4-葡聚糖，分子量6万-200万道尔顿。我国于2014年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 燕麦β-葡聚糖 |
| 英文名称 | Oat β-glucan |
| 来源 | 燕麦麸 |
| 主要成分 | β-1,3-/1,4-葡聚糖 |
| 分子式 | (C₆H₁₂O₆)ₙ |
| 分子量 | 6万-200万道尔顿 |
| 生产工艺 | 以燕麦麸为原料，经水解、提取、沉淀、干燥、灭菌等工艺制成 |
| 推荐食用量 | ≤5 克/天 |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 白色至浅黄色粉末 |
| β-葡聚糖 | ≥70 g/100g |
| 水分 | ≤5 g/100g |
| 灰分 | ≤8 g/100g |
| 铅(Pb) | ≤0.5 mg/kg（2023年第4号增补） |
| 总砷(As) | ≤0.5 mg/kg（2023年第4号增补） |

## 禁忌人群

使用范围不包括婴幼儿食品。

## 国际使用情况

燕麦β-葡聚糖在欧美等国家作为降低胆固醇的功能性食品原料广泛使用，欧盟和美国均批准其健康声称。
