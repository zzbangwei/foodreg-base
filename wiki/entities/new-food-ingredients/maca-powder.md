# 玛咖粉

## 概述

玛咖粉是以人工种植的玛咖（*Lepidium meyenii* Walp）根茎为原料，经切片、干燥、粉碎制成的粉状产品。我国于2011年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 玛咖粉 |
| 拉丁名称 | *Lepidium meyenii* Walp |
| 基本信息 | 种属：人工种植的玛咖（十字花科独行菜属）；食用部位：根茎 |
| 生产工艺简述 | 以玛咖为原料，经切片、干燥、粉碎、灭菌等步骤制成。 |
| 食用量 | ≤25克/天 |

## 质量要求

| 指标 | 要求 |

| 蛋白质含量 | ≥10% |

## 禁忌人群

婴幼儿、哺乳期妇女、孕妇不宜食用。食品的标签、说明书中应当标注不适宜人群和食用限量。
