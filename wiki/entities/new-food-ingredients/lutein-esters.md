# 叶黄素酯

## 概述

叶黄素酯（Lutein Esters），2008年5月26日经卫生部公告（[[weish-2008-12-7-new-resource-foods|2008年第12号]]）批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 叶黄素酯 |
| 英文名称 | Lutein Esters |
| 主要成分 | 叶黄素二棕榈酸酯 |
| CAS | 547-17-1 |
| 来源 | 万寿菊花 |
| 分子式 | C₇₂H₁₁₆O₄ |
| 分子量 | 1045.71 |
| 批准日期 | 2008-05-26 |

## 生产与使用

- **生产工艺**：以万寿菊花为原料，经过脱水粉碎、溶剂提取、低分子量醇纯化和真空浓缩等步骤生产而成。
- **使用范围**：焙烤食品、乳制品、饮料、即食谷物、冷冻饮品、调味品和糖果，**不包括婴幼儿食品**
- **性状**：深红棕色细小颗粒

## 食用量

≤12 毫克/天

## 质量规格

| 指标 | 要求 |
|------|------|
| 叶黄素二棕榈酸酯含量 | >55.8% |
| 玉米黄质酯含量 | <4.2% |
| 正己烷残留 | <10 ppm |
| 乙醇残留 | <10 ppm |

## 批准背景

属于 [[weish-2008-12-7-new-resource-foods|卫生部2008年第12号公告]] 批准的7种新资源食品之一。
