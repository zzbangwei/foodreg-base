# 牛奶碱性蛋白

## 概述

牛奶碱性蛋白（Milk Basic Protein，MBP）是以鲜牛乳为原料，经脱脂、去除酸性蛋白、阳离子层析等工艺制成的碱性蛋白。我国于2009年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 牛奶碱性蛋白 |
| 英文名称 | Milk Basic Protein |
| 基本信息 | 来源：鲜牛乳 |
| 生产工艺简述 | 以鲜牛乳为原料，经脱脂、过滤、浓缩、去除酪蛋白等酸性蛋白、阳离子层析、冷冻干燥等工艺制成。 |
| 食用量 | ≤200毫克/天 |
