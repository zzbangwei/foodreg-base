# 副干酪乳杆菌（菌株号GM080、GMNL-33）

## 概述

副干酪乳杆菌（*Lactobacillus paracasei*），来源为健康人体胃肠道，菌株号为GM080、GMNL-33。我国于2008年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 副干酪乳杆菌 |
| 拉丁名称 | *Lactobacillus paracasei* |
| 基本信息 | 来源：健康人体胃肠道；菌株号：GM080、GMNL-33 |
| 生产工艺简述 | 经发酵培养、离心、急速冷冻、干燥、包装等步骤生产而成。 |
| 使用范围 | 乳制品、保健食品、饮料、饼干、糖果、冰淇淋，但不包括婴幼儿食品 |
| 性状 | 冷冻干燥粉末 |
