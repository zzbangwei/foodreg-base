# 异麦芽酮糖醇

## 概述

异麦芽酮糖醇（Isomaltitol）是以白砂糖为原料，经蔗糖异构酶转化产生的功能性糖醇，主要成分为α-D-吡喃葡萄糖基-1,6-山梨醇（GPS）和α-D-吡喃葡萄糖基-1,1-甘露醇（GPM）的大致等比混合物。我国于2008年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 异麦芽酮糖醇 |
| 英文名称 | Isomaltitol |
| 主要成分 | α-D-吡喃葡萄糖基-1,6-山梨醇（GPS）和α-D-吡喃葡萄糖基-1,1-甘露醇（GPM）大致等比混合物 |
| 基本信息 | 来源：白砂糖；GPS分子式：C₁₂H₂₄O₁₁，分子量：344.32；GPM分子式：C₁₂H₂₄O₁₁·2H₂O，分子量：380.32 |
| 生产工艺简述 | 以白砂糖为原料，经蔗糖异构酶转化产生异麦芽酮糖，催化生成异麦芽酮糖醇溶液；脱色、过滤、离子交换去杂质；浓缩、固化、结晶造粒、分筛。 |
| 食用量 | ≤100克/天 |
