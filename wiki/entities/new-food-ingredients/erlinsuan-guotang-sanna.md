# 1,6-二磷酸果糖三钠盐

## 概述

1,6-二磷酸果糖三钠盐（D-Fructose 1,6-diphosphate trisodium salt），以葡萄糖为原料经酿酒酵母发酵后制成。我国于2013年批准为新食品原料，限用于运动饮料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 1,6-二磷酸果糖三钠盐 |
| 英文名称 | D-Fructose 1,6-diphosphate trisodium salt |
| 来源 | 葡萄糖 |
| 分子式 | C₆H₁₁Na₃O₁₂P₂·8H₂O |
| 分子量 | 550.17 |
| 生产工艺 | 以葡萄糖为原料，经酿酒酵母发酵后，经离子交换、分离、浓缩、喷干等步骤制成 |
| 推荐食用量 | ≤300 毫克/天 |
