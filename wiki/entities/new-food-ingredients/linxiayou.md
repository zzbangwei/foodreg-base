# 磷虾油

## 概述

磷虾油（Krill Oil），来源于磷虾科磷虾属南极大磷虾（*Euphausia superba* Dana），经水洗、破碎、提取、浓缩、过滤等步骤制得。富含磷脂（≥38%）、DHA和EPA。我国于2013年批准为新食品原料。

| 项目 | 内容 |
|------|------|
| 中文名称 | 磷虾油 |
| 英文名称 | Krill Oil |

| 生产工艺 | 以磷虾为原料，经水洗、破碎、提取、浓缩、过滤等步骤制得 |
| 推荐食用量 | ≤3 克/天 |

| 指标 | 要求 |

| DHA | ≥3 g/100g |

## 禁忌人群

婴幼儿、孕妇、哺乳期妇女及海鲜过敏者不宜食用，标签、说明书中应当标注不适宜人群。
