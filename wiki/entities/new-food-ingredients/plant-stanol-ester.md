# 植物甾烷醇酯

## 概述

植物甾烷醇酯（Plant stanol ester），2008年9月9日经卫生部公告（[[weish-2008-20-10-new-resource-foods|2008年第20号]]）首次批准为新资源食品。2014年5月30日，国家卫生计生委通过[[weish-2014-10-塔格糖等6种新食品原料|2014年第10号]]公告扩大其使用范围并增加原料来源。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 植物甾烷醇酯 |
| 英文名称 | Plant stanol ester |
| 分子式 | C₄₇H₈₄O₂ |
| 分子量 | 681.2 |
| 来源（2008） | 大豆油提取的甾醇和食用低芥酸菜籽油制取的脂肪酸甲酯 |
| 来源（2014） | 植物油或塔罗油提取的甾醇和植物油制取的脂肪酸甲酯 |
| 首次批准日期 | 2008-09-09 |
| 最新变更日期 | 2014-05-30 |

## 批准历程

| 日期 | 公告号 | 事项 | 主要内容 |
|------|--------|------|----------|
| 2008-09-09 | [[weish-2008-20-10-new-resource-foods\|2008年第20号]] | 首次批准 | 批准为新资源食品，来源为大豆油提取的甾醇和食用低芥酸菜籽油制取的脂肪酸甲酯 |
| 2014-05-30 | [[weish-2014-10-塔格糖等6种新食品原料\|2014年第10号]] | 扩大范围 | 增加塔罗油为植物甾烷醇酯的原料，扩大使用范围，更新质量要求；该数据更新并取代2008年第20号公告的数据 |

## 生产工艺

植物油甾醇经饱和工艺转化为植物甾烷醇，与脂肪酸甲酯进行酯化反应生成植物甾烷醇酯后再进行清洗、漂白和脱臭处理。

## 使用范围

- **2008年首次批准**：植物油、植物黄油、人造黄油、乳制品、植物蛋白饮料、调味品、沙拉酱、蛋黄酱、果汁、通心粉、面条和速食麦片
- **2014年扩大后**：在上述基础上扩大范围，具体参见2014年第10号公告

## 食用量

＜5 克/天

## 禁忌人群

孕妇和5岁以下儿童不宜食用。标签、说明书中应当标注不适宜人群。

## 质量规格

### 2008年第20号公告（原始规格）

| 指标 | 要求 |
|------|------|
| 植物甾烷醇 | ≥55% |
| 植物甾醇 | ≤5% |
| 游离脂肪酸 | ≤0.1% |
| 干燥失重 | ≤0.1% |

### 2014年第10号公告（更新后规格，含2023年第4号增补）

| 指标 | 要求 |
|------|------|
| 植物甾烷醇 | ≥55% |
| 植物甾醇 | ≤5% |
| 游离脂肪酸 | ≤0.1% |
| 干燥失重 | ≤0.1% |
| 铅（Pb） | ≤0.1 mg/kg（2023年第4号增补） |
| 总砷（As） | ≤0.1 mg/kg（2023年第4号增补） |
| 苯并[α]芘 | ≤10 μg/kg（2023年第4号增补） |

> **注**：2014年第10号公告的质量要求更新并取代了2008年第20号公告的数据。
