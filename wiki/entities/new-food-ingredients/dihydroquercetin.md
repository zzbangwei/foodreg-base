# 二氢槲皮素

## 概述

二氢槲皮素（Dihydroquercetin），化学名称为3,5,7,3',4'-五羟基二氢黄酮，CAS号480-18-2，分子式C₁₅H₁₂O₇。以人工种植的长白落叶松根部为原料，经提取、浓缩、醇沉、萃取、结晶、冷冻真空干燥等工艺制成。我国于2021年批准为新食品原料，可用于特定食品类别。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 二氢槲皮素 |
| 英文名称 | Dihydroquercetin |
| 化学名称 | 3,5,7,3',4'-五羟基二氢黄酮 |
| CAS号 | 480-18-2 |
| 分子式 | C₁₅H₁₂O₇ |
| 来源 | 松科落叶松属落叶松组长白落叶松根部 |
| 生产工艺 | 以人工种植的长白落叶松根部为原料，经去皮、撕裂处理，提取、浓缩、醇沉、上清液浓缩、萃取、再浓缩、结晶、离心分离、冷冻真空干燥、粉碎过筛等工艺制成 |
| 推荐食用量 | ≤100毫克/天（含量为90%时；超过该含量的按照实际含量折算） |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 浅黄色或类白色粉末 |
| 二氢槲皮素含量 | ≥90.0% |
| 铅(Pb) | ≤0.5 mg/kg |
| 砷(As) | ≤0.3 mg/kg |
| 镉(Cd) | ≤0.5 mg/kg |
| 汞(Hg) | ≤0.1 mg/kg |
| 菌落总数 | ≤1000 CFU/g |
| 大肠菌群 | ≤3.0 MPN/g |
| 霉菌和酵母 | ≤100 CFU/g |
| 沙门氏菌 | 不得检出 (/25g) |
| 金黄色葡萄球菌 | 不得检出 (/25g) |

## 禁忌人群

婴幼儿、儿童（14岁及以下）、孕妇、哺乳期妇女不宜食用，标签、说明书应当标注不适宜人群。
