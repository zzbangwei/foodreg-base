# 盐肤木果油

## 概述

盐肤木果油（Sumac Fruit Oil），来源于漆树科盐肤木属盐肤木（*Rhus chinensis* Mill.）果实，经晾晒、压榨、过滤等工艺制成。富含亚油酸（≥55%）。我国于2013年批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 盐肤木果油 |
| 英文名称 | Sumac Fruit Oil |
| 来源 | 漆树科盐肤木属盐肤木（*Rhus chinensis* Mill.）果实 |
| 生产工艺 | 以盐肤木果实为原料，经晾晒、压榨、过滤等工艺而制成 |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 淡黄色至棕黄色油状液体 |
| 亚油酸 (C18:2) | ≥55%（占总脂肪酸含量比） |
| 油酸 (C18:1) | ≥15%（占总脂肪酸含量比） |
| 棕榈酸 (C16:0) | ≥8%（占总脂肪酸含量比） |

## 禁忌人群

使用范围不包括婴幼儿食品。
