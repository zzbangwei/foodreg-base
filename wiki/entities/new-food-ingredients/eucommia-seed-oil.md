# 杜仲籽油

## 概述

杜仲籽油（*Eucommia ulmoides* Oliv. Seed Oil）是以杜仲籽为原料，经物理压榨制成的植物油，富含α-亚麻酸。我国于2009年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 杜仲籽油 |
| 拉丁名称 | *Eucommia ulmoides* Oliv. Seed Oil |
| 基本信息 | 来源：杜仲籽 |
| 生产工艺简述 | 以杜仲籽为原料，经去杂、分离壳仁，对籽仁进行物理压榨、过滤等工艺而制成。 |
| 食用量 | ≤3毫升/天 |

## 批准历程

| 公告 | 日期 | 发布机构 | 食用量 | 使用范围 | 说明 |

## 质量要求

| 指标 | 要求 |
|------|------|
| 性状 | 黄棕色透明油状液体 |
| α-亚麻酸（C18:3） | ≥45% |
| 油酸(C18:1) | ≥13% |
| 亚油酸(C18:2) | ≥10% |
| 棕榈酸(C16:0) | ≥6% |
| 硬脂酸(C18:0) | ≥2% |
