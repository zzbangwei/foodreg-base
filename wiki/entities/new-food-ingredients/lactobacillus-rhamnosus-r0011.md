# 鼠李糖乳杆菌（菌株号R0011）

## 概述

鼠李糖乳杆菌（*Lactobacillus rhamnosus*），菌株号R0011，来源为脱水的发酵牛乳。我国于2008年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 鼠李糖乳杆菌 |
| 拉丁名称 | *Lactobacillus rhamnosus* |
| 基本信息 | 来源：脱水的发酵牛乳；菌株号：R0011 |
| 生产工艺简述 | 经发酵培养、离心、冻干等步骤生产而成。 |
| 使用范围 | 保健食品原料 |
| 性状 | 冷冻干燥粉末或颗粒 |
