# 木姜叶柯

## 概述

木姜叶柯，经公告[[weish-2017-7-乳木果油等10种新食品原料|2017年第7号]]批准为新资源食品/新食品原料。

## 基本信息

### 十、木姜叶柯

| 项目 | 内容 |
|------|------|
| 中文名称 | 木姜叶柯 |
| 英文名称 | Lithocarpus litseifolius folium |
| 基本信息 | 来源：壳斗科柯属植物木姜叶柯 [Lithocarpus litseifolius (Hance) Chun]，主要分布于湖南、福建等地 |
| 生产工艺简述 | 以木姜叶柯的嫩叶（芽）为原料，经采摘、清洗、切碎、烘干等工艺制成。 |
| 推荐食用量 | ≤10克/天（以干品计） |
| 食用方式 | 冲泡 |
| **其他需要说明的情况** | 1. 婴幼儿不宜食用，标签及说明书中应当标注不适宜人群。2. 卫生安全指标应当符合我国相关标准。 |
