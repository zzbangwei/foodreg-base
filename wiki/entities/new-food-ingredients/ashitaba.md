# 明日叶

## 概述

明日叶（Ashitaba）为伞形科植物明日叶（*Angelica keiskei* Koidzumi），以茎和叶为原料，经筛选、清洗、烘干等工艺制成。我国于2019年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 明日叶 |
| 英文名称 | Ashitaba |
| 基源植物 | 伞形科明日叶（*Angelica keiskei* Koidzumi） |
| 生产工艺 | 以明日叶的茎和叶为原料，经筛选、清洗、烘干等工艺制成 |
| 推荐食用量 | 鲜品≤50克/天，干品≤5克/天 |
| 不适宜人群 | 婴幼儿、孕妇及哺乳期妇女 |
