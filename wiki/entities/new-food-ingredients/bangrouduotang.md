# 蚌肉多糖

## 概述

蚌肉多糖（Hyriopsis cumingii polysaccharide），来源于三角帆蚌（*Hyriopsis cumingii*）蚌肉，经提取、酶解、超滤、醇沉、干燥、粉碎等工艺制成。我国于2012年批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 蚌肉多糖 |
| 英文名称 | Hyriopsis cumingii polysacchride |
| 来源 | 三角帆蚌（拉丁学名 *Hyriopsis cumingii*） |
| 生产工艺 | 以三角帆蚌肉为原料，经提取、酶解、超滤、醇沉、干燥、粉碎等步骤制成 |
| 推荐食用量 | ≤2.5 克/天 |

## 批准历程

| 公告 | 日期 | 发布机构 | 说明 |
|------|------|---------|------|
| [[weish-2012-02-bangrouduotang|2012年第2号]] | 2012-01-20 | 卫生部 | **首次批准**为新资源食品。使用范围：调味品、汤料、饮料、冷冻食品。 |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 白色粉末 |
| 粗多糖（以葡萄糖计） | ≥70 g/100g |
| 蛋白质 | ≤8.0% |
| 水分 | ≤9.0% |
| 灰分 | ≤5.0% |
| 铅（以铅计） | ≤0.5 mg/kg |
| 砷（以砷计） | ≤0.5 mg/kg |

## 使用范围

调味品、汤料、饮料、冷冻食品。
