# 顺-15-二十四碳烯酸

## 概述

顺-15-二十四碳烯酸（Cis-15-Tetracosenoic Acid），又称神经酸，以菜籽油为原料经皂化、酸化、萃取、分离、结晶、干燥等工艺制得。我国于2017年批准为新食品原料。

| 项目 | 内容 |
|------|------|
| 中文名称 | 顺-15-二十四碳烯酸 |
| 英文名称 | Cis-15-Tetracosenoic Acid |
| 来源 | 菜籽油 |
| 结构式 | CH₃-(CH₂)₇-CH=CH-(CH₂)₁₁-COOH |
| 分子式 | C₂₄H₄₆O₂ |
| 分子量 | 366.6 |
| 生产工艺 | 以菜籽油为原料，经过皂化、酸化、萃取、分离、结晶、干燥等工艺制得 |
| 推荐食用量 | ≤300 毫克/天 |
