# 短梗五加

## 概述

短梗五加（*Acanthopanax sessiliflorus*），2008年5月26日经卫生部公告（[[weish-2008-12-7-new-resource-foods|2008年第12号]]）批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 短梗五加 |
| 拉丁名称 | *Acanthopanax sessiliflorus* |
| 来源 | 人工种植 |
| 食用部位 | 茎、叶、果 |
| 批准日期 | 2008-05-26 |

## 生产与使用

- **生产工艺**：以短梗五加全株鲜品为原料，经清洗、切片、干燥、杀菌、粉碎等步骤制成。
- **使用范围**：饮料类、酒类
- **性状**：灰褐色固体干燥粉末

## 食用量与禁忌

| 项目 | 内容 |
|------|------|
| 食用量 | ≤4.5克/天 |
| 不适宜人群 | **哺乳期妇女、孕妇、婴幼儿及儿童** |

## 质量规格

| 指标 | 要求 |
|------|------|
| 短梗五加全株干粉 | 100.0% |
| 总皂甙（以人参皂甙Re计） | ≥1.0% |
| 总黄酮（以芦丁计） | ≥0.1% |
| 灰分 | ≤10.0% |
| 水分 | ≤8.0% |

## 批准背景

属于 [[weish-2008-12-7-new-resource-foods|卫生部2008年第12号公告]] 批准的7种新资源食品之一。注意：此批准限用于饮料类和酒类，且有严格的不适宜人群限制。
