# 御米油

## 概述

御米油（Poppyseed oil）是以罂粟的种子为原料，经压榨精制而成的植物油。我国于2010年首次批准为新资源食品，仅限用于食用油，不得再生产加工其他食品、食品添加剂。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 御米油 |
| 英文名称 | Poppyseed oil |
| 基本信息 | 来源：罂粟的种子 |
| 生产工艺简述 | 罂粟籽经清理、去壳，采用压榨等方法制油，并经脱水、脱色、脱臭、精滤等工艺精制而成。 |
| 食用量 | ≤25克/天 |

## 质量要求

| 指标 | 要求 |
|------|------|
| 性状 | 淡黄色半透明油状液体 |
| 棕榈酸(C16:0) | 8.9-10.2% |
| 硬脂酸(C18:0) | 1.5-2.7% |
| 油酸(C18:1) | 15.1-23.5% |
| 亚油酸(C18:2) | 60.0-81.0% |
| 亚麻酸（C18:3） | 0.42-0.90% |

## 禁忌人群

婴幼儿不宜食用，标签、说明书中应当标注不适宜人群和食用限量。

备注：生产经营御米油应符合《关于加强罂粟籽食品监督管理工作的通知》（卫监督发〔2005〕349号）的要求。
