# 共轭亚油酸

## 概述

共轭亚油酸（Conjugated Linoleic Acid，CLA）是以食品级红花籽油为原料，通过共轭化反应得到的脂肪酸，主要异构体为9c,11t和10t,12c。我国于2009年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 共轭亚油酸 |
| 英文名称 | Conjugated Linoleic Acid (CLA) |
| 主要成分 | 共轭亚油酸(C18:2)，主要的异构体为9c,11t和10t,12c的异构体 |
| 基本信息 | 来源：红花籽油；分子式：C₁₈H₃₂O₂；分子量：280.44 |
| 生产工艺简述 | 以食品级的红花籽油为原料，通过共轭化反应将其中的亚油酸转化成共轭亚油酸。 |
| 食用量 | < 6克/天 |
