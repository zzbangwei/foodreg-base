# 塔格糖

## 概述

塔格糖（Tagatose），以半乳糖为原料经异构化等工艺制成的稀有糖，甜度约为蔗糖的92%，热量低（约1.5 kcal/g）。我国于2014年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 塔格糖 |
| 英文名称 | Tagatose |
| 来源 | 半乳糖 |
| 分子式 | C₆H₁₂O₆ |
| 分子量 | 180.16 |
| 生产工艺 | 以半乳糖为原料，经异构化、脱色、脱盐、浓缩、结晶等步骤制成 |

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 白色晶体颗粒或粉末 |
| 塔格糖含量 | ≥98 g/100g |
| 灰分 | ≤0.1 g/100g |
| 铅(Pb) | ≤0.5 mg/kg（2023年第4号增补） |
| 总砷(As) | ≤0.5 mg/kg（2023年第4号增补） |

## 禁忌人群

使用范围不包括婴幼儿食品。
