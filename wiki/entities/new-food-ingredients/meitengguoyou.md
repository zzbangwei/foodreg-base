# 美藤果油

## 概述

美藤果油（Sacha Inchi Oil），来源于大戟科美藤果（*Plukenetia volubilis* L.）种籽，经压榨、过滤等工艺制成。富含α-亚麻酸（≥45%），是一种高含量的omega-3植物油。我国于2013年批准为新资源食品。

## 质量规格

| 指标 | 要求 |
|------|------|
| 性状 | 淡黄色透明油状液体 |
| 亚麻酸 (C18:3) | ≥45%（占总脂肪酸含量比） |
| 亚油酸 (C18:2) | ≥30%（占总脂肪酸含量比） |
| 油酸 (C18:1) | ≥8%（占总脂肪酸含量比） |

## 禁忌人群

使用范围不包括婴幼儿食品。

## 国际使用情况

美藤果油原产于南美洲亚马逊地区，在秘鲁等地有悠久的食用历史。
