# β-羟基-β-甲基丁酸钙 (CaHMB)

## 概述

β-羟基-β-甲基丁酸钙（Calcium β-hydroxy-β-methyl butyrate，CaHMB），是 β-羟基-β-甲基丁酸（HMB）的钙盐。HMB 广泛存在于多种食物中，也是亮氨酸在人体内的次要代谢产物。我国自 2011 年起分三个阶段批准其使用范围和食用量。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | β-羟基-β-甲基丁酸钙 |
| 英文名称 | Calcium β-hydroxy-β-methyl butyrate (CaHMB) |
| 分子式 | (C₅H₉O₃)₂Ca·H₂O |
| 分子量 | 292 |
| 生产工艺简述 | 以次氯酸钠、二丙酮醇、盐酸、乙酸乙酯、乙醇、氢氧化钙为主要原料，经氧化合成、酸化、萃取、中和反应、离心、干燥等步骤生产而成。 |
| 性状 | 白色粉末 |

## 质量要求

| 指标 | 要求 |
|------|------|
| β-羟基-β-甲基丁酸 | 77-82% |
| 钙 | 12-16% |
| 水分 | 5-7.5% |

## 禁忌人群

孕妇、哺乳期妇女、婴幼儿及儿童不宜食用，标签及说明书中应当标注不适宜人群和食用限量。

## 国际使用情况

欧盟、美国、日本、新加坡等多个国家和地区已批准使用。已通过美国 FDA 的 GRAS（一般认为安全的物质）认定。
