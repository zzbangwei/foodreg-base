# N-乙酰氨基葡萄糖

## 概述

N-乙酰氨基葡萄糖是以葡萄糖、玉米浆干粉、硫酸铵、磷酸二氢钾、硫酸镁为原料，经谷氨酸棒杆菌RDG-2110（*Corynebacterium glutamicum* RDG-2110）发酵、过滤、浓缩、结晶、离心、醇洗、干燥等工艺制成。我国于2024年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | N-乙酰氨基葡萄糖 |
| 生产菌种 | 谷氨酸棒杆菌RDG-2110（*Corynebacterium glutamicum* RDG-2110） |
| 生产工艺 | 经发酵、过滤、浓缩、结晶、离心、醇洗、干燥等工艺制成 |
| 推荐食用量 | ≤500毫克/天（以干基计） |
| 不适宜人群 | 婴幼儿、孕妇和哺乳期妇女 |
