# 赶黄草

## 概述

赶黄草为虎耳草科扯根菜属植物赶黄草（*Penthorum chinense* Pursh）的干燥地上部分，食用方式为冲泡。我国于2020年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 赶黄草 |
| 英文名称 | Penthorum chinense Pursh |
| 基源植物 | 虎耳草科扯根菜属植物赶黄草（*Penthorum chinense* Pursh）的干燥地上部分 |
| 推荐食用量 | ≤10克/天 |
| 食用方式 | 冲泡 |
| 不适宜人群 | 婴幼儿、少年儿童、孕妇及哺乳期妇女 |
