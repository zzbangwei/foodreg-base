# 水解蛋黄粉

## 概述

水解蛋黄粉（Bonepep）是以鸡蛋蛋黄为原料，经蛋白酶处理制成的寡肽混合物。我国于2008年首次批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 水解蛋黄粉 |
| 英文名称 | Bonepep |
| 基本信息 | 来源：鸡蛋蛋黄 |
| 生产工艺简述 | 以鸡蛋蛋黄为原料，经蛋白酶处理、加热、离心分离、喷雾干燥等步骤生产而成。 |
| 食用量 | ≤1克/天 |
| 性状 | 白色至淡黄色粉末 |
