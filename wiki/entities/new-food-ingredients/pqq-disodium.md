# 吡咯并喹啉醌二钠盐 (PQQ)

## 概述

吡咯并喹啉醌二钠盐（Pyrroloquinoline quinone disodium salt，PQQ·Na₂）是一种氧化还原辅因子，天然存在于多种食物如牛奶、鸡蛋、菠菜等中。我国于2022年首次批准合成法产品，2023年新增发酵法工艺路线。PQQ在美国被作为"一般认为安全的物质（GRAS）"管理，欧盟和加拿大作为膳食补充剂或天然保健食品。

| 中文名称 | 吡咯并喹啉醌二钠盐 |
| 英文名称 | Pyrroloquinoline quinone disodium salt (PQQ·Na₂) |
| 缩写 | PQQ |
| 化学名称 | 4,5-二氢-4,5-二氧代-1H-吡咯并[2,3-f]喹啉-2,7,9-三羧酸二钠盐 |
| 自然存在 | 牛奶、鸡蛋、菠菜等多种食物 |
| 纯度要求 | ≥98.0 g/100g（以干基计） |

## 禁忌人群

婴幼儿、孕妇及哺乳期妇女不宜食用。标签及说明书中应当标注不适宜人群和食用限量。

## 国际使用情况

- **美国**：被作为"一般认为安全的物质（GRAS）"管理，可用于能量饮料、运动饮料、电解质饮料等食品
- **欧盟**：作为膳食补充剂
- **加拿大**：作为天然保健食品
