# 蝉花子实体（人工培植）

## 概述

蝉花子实体（人工培植），拉丁名 *Cordyceps cicadae*，属虫草科、棒束孢属。以蝉花菌种经接种、培养、采收、干燥等工艺制成。我国于2021年（2020年第9号公告）批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 蝉花子实体（人工培植） |
| 英文名称 | Cordyceps cicadae (artificially cultivated) |
| 种属 | 虫草科、棒束孢属 |
| 生产工艺 | 以蝉花（*Cordyceps cicadae*）菌种经接种、培养、采收、干燥等工艺制成 |
| 推荐食用量 | ≤3克/天（以干品计） |

婴幼儿、孕妇、哺乳期妇女及食用菌过敏者不宜食用，标签及说明书中应当标注不适宜人群。
