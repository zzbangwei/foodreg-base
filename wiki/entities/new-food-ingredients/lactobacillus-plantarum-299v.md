# 植物乳杆菌（菌株号299v）

## 概述

植物乳杆菌（*Lactobacillus Plantarum*），菌株号299v，来源为脱水的发酵牛乳。我国于2008年首次批准为新资源食品。该物种后经2022年第4号公告更名为植物乳植杆菌（*Lactiplantibacillus plantarum*）。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 植物乳杆菌 |
| 拉丁名称 | *Lactobacillus Plantarum* |
| 基本信息 | 来源：脱水的发酵牛乳；菌株号：299v |
| 生产工艺简述 | 经发酵培养、离心、冻干等步骤生产而成。 |
| 使用范围 | 乳制品、保健食品，但不包括婴幼儿食品 |
| 性状 | 冷冻干燥粉末 |
