# 低聚甘露糖

## 概述

低聚甘露糖，经公告[[weish-2013-10-luozao|2013年第10号]]批准为新资源食品/新食品原料。

## 基本信息

### 八、低聚甘露糖

| 项目 | 内容 |
| --- | --- |
| 中文名称 | 低聚甘露糖 |
| 基本信息 | 来源：魔芋粉；分子式：（C6H10O5）n，n为2-10；分子量：342.3-1639.44 |
| 生产工艺简述 | 以魔芋粉为原料，经半纤维素酶酶解、分离、提纯生产而成。 |
| 食用量 | ≤1.5克/天 |
| 质量要求 | 低聚甘露糖（甘露二糖-甘露十糖）含量（以干基计）(g/100g)：≥85；甘露二糖-甘露六糖含量（以干基计）(g/100g)：≥50 |
