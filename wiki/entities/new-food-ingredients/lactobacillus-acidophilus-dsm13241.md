# 嗜酸乳杆菌（DSM13241）

## 概述

嗜酸乳杆菌（*Lactobacillus acidophilus*），菌株号 DSM13241，2008年5月26日经卫生部公告（[[weish-2008-12-7-new-resource-foods|2008年第12号]]）批准为新资源食品。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 嗜酸乳杆菌 |
| 拉丁名称 | *Lactobacillus acidophilus* |
| 来源 | 乳品发酵剂 |
| 菌株号 | DSM13241 |
| 批准日期 | 2008-05-26 |

## 生产与使用

- **生产工艺**：经发酵培养、离心、干燥等步骤生产而成。
- **使用范围**：乳制品、保健食品，**不包括婴幼儿食品**
- **性状**：冷冻干燥粉末

## 质量规格

| 指标 | 要求 |
|------|------|
| 嗜酸乳杆菌活菌数 | ≥3.0×10^10 cfu/g |
| 水分 | ≤4.0% |
| 菌液形态水分 | >80%（如以菌液形式） |

## 批准背景

属于 [[weish-2008-12-7-new-resource-foods|卫生部2008年第12号公告]] 批准的7种新资源食品之一，依据《中华人民共和国食品卫生法》和《新资源食品管理办法》审批。
