# 线叶金雀花

## 概述

线叶金雀花（*Aspalathus Linearis*），又称南非博士茶（Rooibos），来源于南非的豆科植物，食用部位为叶子和细茎，食用方式为冲泡。我国于2014年批准为新食品原料。

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文名称 | 线叶金雀花 |
| 拉丁名称 | *Aspalathus Linearis* (Brum.f.) R.Dahlgren |
| 来源 | 南非的豆科（Leguminosae）植物 |
| 食用部位 | 叶子和细茎 |
| 食用方式 | 冲泡 |

## 国际使用情况

线叶金雀花（Rooibos）在南非有数百年的饮用历史，在国际市场上作为天然无咖啡因草本茶广泛流行。
