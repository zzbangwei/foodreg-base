# 关于瑞士乳杆菌R0052等53种"三新食品"的公告（2020年第4号）

2020年 第4号

根据《食品安全法》规定，审评机构组织专家对瑞士乳杆菌R0052等4种新食品原料、三赞胶等21种食品添加剂新品种、辛酸锌等28种食品相关产品新品种的安全性评估材料审查并通过。

特此公告。

## 新食品原料部分（共4种）

### 一、瑞士乳杆菌R0052

| 项目 | 内容 |
|------|------|
| 中文名称 | 瑞士乳杆菌R0052 |
| 拉丁名称 | Lactobacillus helveticus R0052 |
| **其他需要说明的情况** | 1. 可用于婴幼儿食品的菌种。2. 食品安全指标应符合我国相关标准。 |

### 二、婴儿双歧杆菌R0033

| 项目 | 内容 |
|------|------|
| 中文名称 | 婴儿双歧杆菌R0033 |
| 拉丁名称 | Bifidobacterium infantis R0033 |
| **其他需要说明的情况** | 1. 可用于婴幼儿食品的菌种。2. 食品安全指标应符合我国相关标准。 |

### 三、两歧双歧杆菌R0071

| 项目 | 内容 |
|------|------|
| 中文名称 | 两歧双歧杆菌R0071 |
| 拉丁名称 | Bifidobacterium bifidum R0071 |
| **其他需要说明的情况** | 1. 可用于婴幼儿食品的菌种。2. 食品安全指标应符合我国相关标准。 |

### 四、赶黄草

| 项目 | 内容 |
|------|------|
| 中文名称 | 赶黄草 |
| 英文名称 | Penthorum chinense Pursh |
| 基本信息 | 来源：虎耳草科扯根菜属植物赶黄草（Penthorum chinense Pursh）的干燥地上部分 |
| 推荐食用量 | ≤10克/天 |
| 食用方式 | 冲泡 |
| **其他需要说明的情况** | 1. 婴幼儿、少年儿童、孕妇及哺乳期妇女不宜食用，标签及说明书中应当标注不适宜人群。2. 食品安全指标应符合我国相关标准。 |

> **注**：本公告同时含21种食品添加剂新品种和28种食品相关产品新品种，此处仅提取了新食品原料部分。
