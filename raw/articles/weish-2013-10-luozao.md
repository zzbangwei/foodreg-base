# 关于批准裸藻等8种新食品原料的公告

**国家卫生计生委公告2013年第10号**

根据《中华人民共和国食品安全法》和《新食品原料安全性审查管理办法》有关规定，现批准裸藻、1,6-二磷酸果糖三钠盐、丹凤牡丹花、狭基线纹香茶菜、长柄扁桃油、光皮梾木果油、青钱柳叶、低聚甘露糖为新食品原料。生产经营上述食品应当符合有关法律、法规、标准规定。

特此公告。

国家卫生计生委
2013年10月30日

## 附件：裸藻等8种新食品原料

### 一、裸藻

| 项目 | 内容 |
| --- | --- |
| 中文名称 | 裸藻 |
| 英文名称 | Euglena gracilis |
| 基本信息 | 种属：裸藻门、裸藻目、裸藻属 |
| 其他需要说明的情况 | 1.使用范围不包括婴幼儿食品。2.卫生安全指标应当符合我国相关标准。 |

### 二、1,6-二磷酸果糖三钠盐

| 项目 | 内容 |
| --- | --- |
| 中文名称 | 1,6-二磷酸果糖三钠盐 |
| 英文名称 | D-Fructose 1,6-diphosphate trisodium salt |
| 基本信息 | 来源：葡萄糖；分子式：C6H11Na3O12P2·8H2O；分子量：550.17 |
| 生产工艺简述 | 以葡萄糖为原料，经酿酒酵母发酵后，经过离子交换、分离、浓缩、喷干等步骤而制成。 |
| 食用量 | ≤300毫克/天 |
| 其他需要说明的情况 | 1.使用范围：运动饮料。2.婴幼儿、孕妇不宜食用，标签、说明书中应当标注不适宜人群和食用限量。3.卫生安全指标应当符合我国相关标准。 |

| --- | --- |

| 基本信息 | 来源：丹凤牡丹（拉丁名称：Paeonia ostii T.Hong et J.X.Zhang）；食用部位：花 |

### 四、狭基线纹香茶菜
