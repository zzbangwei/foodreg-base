# 知识库管理优化方案

> **核心目标**: 规范化管理 + 查询速度提升
> **适用范围**: 中国食品法规标准（GB 体系），聚焦国内
> **方案性质**: AI 综合设计，建议人工审阅后实施

---

## 一、现状与目标

### 1.1 中国食品法规知识库的核心挑战

| 挑战 | 说明 |
|------|------|
| **高频更新** | GB 标准每 3-5 年修订，添加剂列表频繁调整，卫健委公告持续发布 |
| **复杂关联** | 一项物质横跨多个标准——限量 (GB 2760) + 检测方法 (GB 5009) + 标签 (GB 7718) |
| **标准间交叉引用** | GB 2760 引用 GB 2761/2762/14880，一个条款依赖多个标准的定义和分类 |
| **精确查询** | 用户需要"苯甲酸在乳制品中的最大使用量"，而非泛读全文 |
| **版本追踪** | 必须区分"现行版本"和"历史版本"，如 GB 2760-2024 vs GB 2760-2014 |

### 1.2 优化目标

```
规范化管理  →  统一格式、分类清晰、版本可溯、可协作
查询提速    →  秒级定位、按物质/类别/标准号多维过滤
```

## 二、规范化管理体系

### 2.1 三层架构强制分离

```
raw/        ← 原始资料：GB 标准原文、公告、解读（只读，不修改）
wiki/       ← 编译知识：LLM 维护的半结构化 Markdown
SCHEMA.md   ← 规则配置：统一规范与约束
```

> **关键原则**：用户永远不改 wiki，LLM 永远不改 raw。职责边界清晰。

### 2.2 文件命名规范 — 前缀分类法

采用**前缀 + 内容**的命名模式，一目了然：

```
standard-gb-2760.md          ← 标准实体页
standard-gb-2761.md          ← 同上
standard-gb-7718.md          ← 同上
org-nhc.md                   ← 机构页（卫健委）
org-cfsa.md                  ← 机构页（国家食品安全风险评估中心）
substance-benzoic-acid.md    ← 物质页
substance-sodium-benzoate.md ← 物质页
concept-adi.md               ← 概念页（每日允许摄入量）
concept-haccp.md             ← 概念页
method-gb-5009-28.md         ← 检测方法页
topic-preservatives-cn.md    ← 主题综述：中国防腐剂体系
comparison-gb2760-gb14880.md ← 跨标准对比：2760 vs 14880 同一物质的差异
```

**好处**：
- 同类型文件按字母自然聚拢，文件列表即粗略索引
- `grep "standard-" wiki/index.md` 秒查所有标准
- 彻底消除"GB2760.md / gb-2760.md / GB_2760.md"的命名混乱

### 2.3 强制 YAML Frontmatter — 结构化元数据

每个页面开头必须包含机器可读元数据，这是查询加速的基石：

```yaml
---
title: "GB 2760-2024 食品安全国家标准 食品添加剂使用标准"
type: entity
created: 2026-06-25
updated: 2026-06-25
sources: [raw/gb-2760-2024.md]
tags: [食品添加剂, 限量标准, 防腐剂, 着色剂]
standard_type: 基础标准
food_category: [乳及乳制品, 饮料, 肉及肉制品]
substance_type: [防腐剂, 着色剂, 甜味剂]
status: current
replaces: GB 2760-2014
replaced_by: null
---
```

| 字段 | 说明 | 查询用途 |
|------|------|----------|
| `tags` | 灵活标签 | `grep "tags:.*防腐剂" wiki/` |
| `standard_type` | 标准类型（基础/产品/方法/规范） | 按类型过滤 |
| `food_category` | 涉及的食品类别 | 按类别过滤 |
| `substance_type` | 涉及的物质类型 | 按物质组过滤 |
| `status` | current / outdated / draft | 只看现行标准 |
| `replaces` / `replaced_by` | 版本链 | 追溯标准演进 |

### 2.4 分类体系标准化

#### 标准类型（standard_type）

| 类型 | 说明 | 典型标准 |
|------|------|----------|
| **基础标准** | 限量和通用要求 | GB 2760, GB 2761, GB 2762, GB 29921 |
| **产品标准** | 具体食品产品要求 | GB 19644（乳粉）, GB 10765（婴儿配方） |
| **检验方法** | 检测方法标准 | GB 5009 系列, GB 4789 系列 |
| **生产规范** | GMP/HACCP 等 | GB 14881, GB 12693 |
| **标签标识** | 标签与声称 | GB 7718, GB 28050 |
| **包装材料** | 食品接触材料 | GB 4806 系列, GB 9685 |
| **特殊食品** | 保健食品/特膳 | GB 16740, GB 24154 |
| **公告/通知** | 卫健委/市监局公告 | 新食品原料公告、添加剂增补公告 |

#### 食品类别（food_category）

采用 GB 2760-2024 附录 E 的食品分类系统，一级分类：

```
01.0 乳及乳制品
02.0 脂肪、油和乳化脂肪制品
03.0 冷冻饮品
04.0 水果、蔬菜、豆类、食用菌、藻类等
05.0 可可制品、巧克力和巧克力制品及糖果
06.0 粮食和粮食制品
07.0 焙烤食品
08.0 肉及肉制品
09.0 水产及其制品
10.0 蛋及蛋制品
11.0 甜味料
12.0 调味品
13.0 特殊膳食用食品
14.0 饮料类
15.0 酒类
16.0 其他类
```

> 完整的二级、三级子类参照 GB 2760-2024 附录 E。

#### 物质类型（substance_type）

```
食品添加剂
├── 防腐剂         # 苯甲酸、山梨酸、脱氢乙酸...
├── 着色剂         # 柠檬黄、日落黄、诱惑红...
├── 甜味剂         # 阿斯巴甜、三氯蔗糖、甜菊糖苷...
├── 乳化剂         # 单硬脂酸甘油酯、卵磷脂...
└── 增稠剂/抗氧化剂/酸度调节剂/膨松剂...

限量物
├── 农药残留       # GB 2763
├── 兽药残留       # GB 31650
├── 真菌毒素       # GB 2761
├── 污染物         # GB 2762（铅、镉、汞、砷...）
└── 致病菌         # GB 29921（沙门氏菌、金黄色葡萄球菌...）

营养相关
├── 营养强化剂     # GB 14880
└── 新食品原料     # 卫健委公告
```

### 2.5 页面内容规范

每个页面必须包含以下固定区块：

| 区块 | 必须 | 说明 |
|------|------|------|
| Frontmatter | ✅ | YAML 元数据 |
| 基本信息 | ✅ | 标准号、发布机构、实施日期、版本链 |
| 核心内容 | ✅ | 关键条款和数据 |
| 关联页面 | ✅ | `[[wiki-links]]` 交叉引用 |
| 引用来源 | ✅ | 指向 raw/ 文件 |
| 变更记录 | ✅ | 操作时间线 |

> 完整模板见 `SCHEMA.md`。

### 2.6 版本管理与标准替代追踪

法规类页面必须追踪版本演进：

```markdown
## 版本历史
| 版本 | 实施日期 | 状态 | 替代关系 |
|------|----------|------|----------|
| GB 2760-2024 | 2025-02-08 | ✅ 现行 | 替代 GB 2760-2014 |
| GB 2760-2014 | 2015-05-24 | 🔔 已废止 | 替代 GB 2760-2011 |
| GB 2760-2011 | 2011-06-20 | 🔔 已废止 | 替代 GB 2760-2007 |
```

> ⚠️ 被替代的标准页面 **不删除**，`status` 标记为 `outdated`，`replaced_by` 指向新版，保留历史可追溯性。

## 三、查询速度提升策略

### 3.1 核心思路：编译期投入 → 查询期收获

```
传统流程：查一个物质 → 翻遍多个 PDF → 手工摘录 → 数分钟
优化流程：Ingest 时完成索引+交叉引用 → Query 时走索引 → 秒级定位
```

**本质是"空间换时间"**：在 Wiki 编译阶段多花 1-2 分钟建立关联，换来查询时的 O(1) 命中。

### 3.2 多层索引体系

#### L1 — 总索引 `wiki/index.md`

三维组织入口，查询时先读此文件确定目标页面：

```
查询: "苯甲酸在GB 2760中乳制品限量"
  → 读 wiki/index.md
  → 物质入口 → entities/substance-benzoic-acid
  → 标准入口 → entities/standard-gb-2760
  → 读取两个页面，提取交叉引用中的具体条款
  → 返回: "≤ 0.03 g/kg（以苯甲酸计）"
```

#### L2 — 标签 + 字段过滤（grep 即查询）

基于 frontmatter 中的结构化学段实现多维过滤：

```bash
# 按物质类型查：所有"防腐剂"相关标准
rg "tags:.*防腐剂" wiki/ --type md

# 按食品类别查：所有涉及"乳及乳制品"的页面
rg "food_category:.*乳及乳制品" wiki/

# 按标准类型查：所有"基础标准"
rg "standard_type:.*基础标准" wiki/

# 组合条件：现行 + 食品添加剂 + 乳制品
rg "status:.*current" wiki/ -l | xargs rg "food_category:.*乳及乳制品"
```

#### L3 — 自动生成子索引

当某分类下页面超过 20 个时，LLM 自动生成子索引页面：

```
wiki/topics/index-preservatives.md      ← 防腐剂子索引
wiki/topics/index-dairy-standards.md    ← 乳制品相关标准汇总
wiki/topics/index-standard-type-base.md ← 基础标准子索引
```

#### L4 — `substance-` 页作为"物质枢纽"

每个物质页是天然的核心查询入口——在一页聚合：

```markdown
# 苯甲酸 (Benzoic Acid)

## 在各标准中的出现
- [[standard-gb-2760]] — 防腐剂限量：乳制品 ≤ 0.03 g/kg
- [[standard-gb-2761]] — （无直接限量，不属于真菌毒素）
- [[standard-gb-2762]] — （不属于污染物限量管控范围）
- [[standard-gb-5009-28]] — 检测方法：HPLC 测定

## 产品应用速查表
| 食品类别 | 最大使用量 | 使用方式 |
|----------|-----------|----------|
| 风味发酵乳 | 0.03 g/kg | 以苯甲酸计 |
| 果酱 | 1.0 g/kg | 以苯甲酸计 |
| ...
```

**用户查一个物质，直接读这一页就够了。**

### 3.3 全文检索 — ripgrep 秒级命中

Markdown + ripgrep 天然适配：

```bash
# 精确：找"苯甲酸钠"所有位置
rg "苯甲酸钠" wiki/ --type md

# 正则：找所有 ≤ x.xx g/kg 的限量值
rg "≤\s*\d+\.?\d*\s*g/kg" wiki/

# 带上下文：确认匹配前的标准名称和食品类别
rg "苯甲酸.*g/kg" -B 5 wiki/

# 跨 raw + wiki 联查
rg "ADI.*mg" raw/ wiki/

# 查所有"不得检出"的条款
rg "不得检出" wiki/
```

> ripgrep 对 1000+ Markdown 文件搜索速度通常 **< 50ms**。

### 3.4 预计算对比表 — 高频查询一次编译、永久秒查

**跨标准对比**（同一物质在不同 GB 标准中的规定）：

```
Q: "苯甲酸在 GB 2760 和 GB 14880 中的要求有什么不同？"
  → 已有: wiki/topics/comparison-benzoic-2760-vs-14880.md
  → 直接读取，无需每次计算
```

**版本对比**（同一标准的新旧版本差异）：

```
Q: "GB 2760-2024 相比 2014 版，防腐剂限量有哪些变化？"
  → 已有: wiki/topics/comparison-gb2760-2024-vs-2014.md
  → 直接读取
```

**跨类别对比**（同一物质在不同食品类别中的限量）：

```
Q: "苯甲酸在乳制品和饮料中的限量分别是多少？"
  → substance- 页中已有的速查表
  → 或 comparison-benzoic-dairy-vs-beverage.md
```

> 策略：查询被问了 ≥2 次，或 LLM 综合了 ≥3 个来源，立即归档为 `comparison-` 页。

### 3.5 查询模板 — 结构化查询路径

| 查询模式 | 触发词 | 执行路径 |
|----------|--------|----------|
| **物质查限量** | "XX 的最大使用量" / "XX 限量" | → `substance-` 页 → 速查表 → 关联 `standard-` 页 |
| **标准查条款** | "GB 2760 关于 XX" / "XX 标准怎么说" | → `standard-` 页 → 定位具体条款 |
| **按食品类别查** | "乳制品相关的标准" / "饮料要符合哪些标准" | → `food_category` 标签过滤 → 汇总 |
| **版本对比** | "GB 2760 新旧版本差异" | → `comparison-` 页 或 substance 页版本历史 |
| **跨标准关联** | "XX 在 2760 和 7718 中的规定" | → `substance-` 页的"在各标准中的出现"区块 |
| **检测方法** | "XX 用什么方法检测" | → `method-gb-5009-xx` 页 |
| **最新法规** | "最新的 XX 标准" | → `status: current` + `updated` 排序 |

### 3.6 反向链接网络

知识库配合 Obsidian 查看时：
- **Graph View** 可视化页面引用关系，一眼看清知识结构
- **发现孤立页面** — 0 入链可能意味着该页面无用或遗漏了交叉引用
- **发现枢纽页面** — 入链最多的核心概念（如"食品添加剂""GB 2760"）

## 五、工具链集成

| 工具 | 用途 | 为什么推荐 |
|------|------|------------|
| **Obsidian** | Wiki 浏览 + 图视图 | 原生 `[[wiki-link]]`，Graph View 可视化关联网络 |

| **Marp** | 生成简报 | Markdown 直接转 PPT |
| **WorkBuddy + LLM Wiki** | AI 编译引擎 | 自动化 Ingest / Query / Lint |

WHERE status = "outdated"
SORT updated DESC
