# 关于食叶草等15种"三新食品"的公告（2021年第9号）

2021年 第9号

根据《食品安全法》规定，审评机构组织专家对食叶草等1种新食品原料、蛋白酶等9种食品添加剂新品种和扩大使用范围的食品添加剂二氢槲皮素等5种食品相关产品新品种的安全性评估材料审查并通过。

特此公告。

## 新食品原料部分（共1种）

### 食叶草

> **数据来源**：国家卫健委2021年第9号公告解读文件及附件。xinshipin.sy.foodvip.net 尚未收录此条目。

| 项目 | 内容 |
|------|------|
| **中文名称** | 食叶草 |
| **英文名称** | Edible dock |
| **基本信息** | 来源：蓼科酸模属食叶草（*Rumex patientia* L. × *Rumex tianschanicus* A. Los.），是以我国引进的鲁梅克斯K-1酸模为母本、黑龙江省密山县野生巴天酸模为父本，通过杂交选育生成的多年生蓼科酸模属草本植物。食用部位为嫩叶或茎叶。 |
| **生产工艺简述** | 以食叶草的嫩叶或茎叶为原料，经清洗、漂烫、冷却、脱水、烘干等工艺制成。 |
| **推荐食用量** | ≤30克/天（以干品计） |
| **不适宜人群** | 婴幼儿、孕妇及哺乳期妇女 |
| **标签标注要求** | 标签及说明书中应当标注不适宜人群。 |
| **质量要求** | 食品安全指标按照我国现行食品安全国家标准中蔬菜的规定执行。 |
| **其他需要说明的情况** | 食叶草在我国河北、河南、山东、山西、陕西、甘肃等多个省份均有种植并食用，食用方式有凉拌、榨汁、炒菜、泡茶、制作豆腐和面食等，未见人群食用不良反应报道。 |

> **注**：本公告同时含9种食品添加剂新品种（蛋白酶、谷氨酰胺酶、木聚糖酶、非洲竹芋提取物等）和5种食品相关产品新品种以及扩大使用范围的食品添加剂，此处仅提取了新食品原料部分。
