# 2018年第10号 — 黑果腺肋花楸果等2种新食品原料

## 公告正文（PDF附件提取）

> **注**：2018年公告PDF为扫描图片格式，以下数据来自官方公报及三新食品目录。

### （一）黑果腺肋花楸果

| 项目 | 内容 |
|------|------|
| 中文名称 | 黑果腺肋花楸果 |
| 英文名称 | Black chokeberry |
| 拉丁名称 | Aronia melanocarpa (Michx.) Ell. |
| 基本信息 | 种属：蔷薇科、腺肋花楸属。食用部位：果实。黑果腺肋花楸是一种从国外引进的蔷薇科、腺肋花楸属灌木浆果果树，其果实在欧亚及北美等国家具有较长食用历史，主要被用来生产着色剂、糖浆、果汁、果酱及果酒等。我国部分地区自2005年开始引种黑果腺肋花楸，目前已在辽宁、江苏、浙江、吉林等多个省区内种植。 |
| 推荐食用量 | ≤10 克/天（以鲜品计） |
| 不适宜人群 | 婴幼儿、孕妇及哺乳期妇女 |
| 食品安全指标 | 按照食品安全国家标准中有关水果（浆果）的规定执行 |

> 婴幼儿、孕妇及哺乳期妇女不宜食用，标签及说明书中应当标注不适宜人群。

### （二）球状念珠藻（葛仙米）

| 项目 | 内容 |
|------|------|
| 中文名称 | 球状念珠藻（葛仙米） |
| 拉丁名称 | Nostoc sphaeroides |
| 基本信息 | 种属：念珠藻科、念珠藻属。为淡水藻类，主要分布在我国湖北、湖南、四川等省区。在我国湖北、湖南等省局部地区有食用历史，可直接烹饪食用，也可制成干品待食用时复水后烹饪食用。 |
| 推荐食用量 | ≤3 克/天（以干品计），鲜品食用量以干品重量折算 |
| 不适宜人群 | 婴幼儿、孕妇及哺乳期妇女 |
| 食品安全指标 | 参照我国现行食品安全国家标准中藻类及其制品的规定执行（由2023年第4号公告修订） |

> 标签及说明书中应当标注不适宜人群。

## 官方解读

根据《食品安全法》规定，审评机构组织专家对黑果腺肋花楸果等2种新食品原料的安全性评估材料审查并通过。

黑果腺肋花楸果（Aronia melanocarpa）属于蔷薇科腺肋花楸属，原产于北美，其果实在欧亚及北美等国家具有较长食用历史。我国部分地区自2005年开始引种，目前已在辽宁、江苏、浙江、吉林等多个省区内种植。推荐食用量为≤10克/天（以鲜品计），婴幼儿、孕妇及哺乳期妇女不宜食用。

球状念珠藻（葛仙米）为念珠藻科念珠藻属淡水藻类，主要分布在我国湖北、湖南、四川等省区，在我国局部地区有食用历史。推荐食用量为≤3克/天（以干品计），婴幼儿、孕妇及哺乳期妇女不宜食用。
