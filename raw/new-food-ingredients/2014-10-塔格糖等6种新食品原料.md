# 关于批准塔格糖等6种新食品原料的公告（2014年第10号）

2014年 第10号

根据《中华人民共和国食品安全法》和《新食品原料安全性审查管理办法》有关规定，现批准塔格糖、奇亚籽、圆苞车前子壳为新食品原料；同意罗伊氏乳杆菌（菌株号DSM17938）用于婴幼儿食品；变更原卫生部2009年第3号公告批准蛹虫草的食用量、质量指标要求和使用范围；增加塔罗油为原卫生部2008年第20号公告批准植物甾烷醇酯的原料，并扩大植物甾烷醇酯使用范围。生产经营上述食品应当符合有关法律、法规、标准规定。

特此公告。

## 附件：塔格糖等6种新食品原料

> **数据来源**：xinshipin.sy.foodvip.net 食品原料查询数据库

### 1. 塔格糖

| 项目 | 内容 |
|------|------|
| **中文名称** | 塔格糖 |
| **英文名称** | Tagatose |
| **基本信息** | 来源：半乳糖。分子式：C₆H₁₂O₆，分子量：180.16 |
| **生产工艺简述** | 以半乳糖为原料，经异构化、脱色、脱盐、浓缩、结晶等步骤制成。 |
| **质量要求** | |
| 　性状 | 白色晶体颗粒或粉末 |
| 　塔格糖含量 | ≥98 g/100g |
| 　灰分 | ≤0.1 g/100g |
| 　铅(Pb) | ≤0.5 mg/kg（2023年第4号增补） |
| 　总砷(As) | ≤0.5 mg/kg（2023年第4号增补） |
| **使用范围** | 不包括婴幼儿食品 |

### 2. 奇亚籽

| 项目 | 内容 |
|------|------|
| **中文名称** | 奇亚籽 |
| **英文名称** | Chia seed |
| **基本信息** | 来源：唇形科鼠尾草属芡欧鼠尾草（拉丁学名：*Salvia hispanica* L.）；食用部位：种子 |
| **使用范围** | 不包括婴幼儿食品 |
| **其他需要说明的情况** | 食品安全指标按照我国现行食品安全国家标准中坚果与籽类的规定执行（由2023年第4号公告修订） |

### 3. 圆苞车前子壳

| 项目 | 内容 |
|------|------|
| **中文名称** | 圆苞车前子壳 |
| **英文名称** | Psyllium seed husk |
| **基本信息** | 来源：人工种植的车前科车前属圆苞车前（拉丁学名：*Plantago ovata*）；食用部位：种子外壳 |
| **生产工艺简述** | 以圆苞车前种子外壳为原料，经碾磨后制得。 |
| **质量要求** | |
| 　性状 | 白色或浅褐色壳片或粉末 |
| 　膳食纤维含量 | ≥80 g/100g |
| 　水分 | ≤12 g/100g |
| 　灰分 | ≤4 g/100g |
| 　黄曲霉毒素B1 | ≤5.0 μg/kg（2023年第4号增补） |
| 　铅(Pb) | ≤1.0 mg/kg（2023年第4号增补） |
| 　总汞(Hg) | ≤0.02 mg/kg（2023年第4号增补） |
| 　总砷(As) | ≤0.5 mg/kg（2023年第4号增补） |
| 　铜(Cu) | ≤5.0 mg/kg（2023年第4号增补） |
| 　菌落总数 | ≤20000 CFU/g（2023年第4号增补） |
| 　大肠菌群 | ≤0.4 MPN/g（2023年第4号增补） |
| **使用范围** | 不包括婴幼儿食品 |

### 5. 蛹虫草（变更原2009年第3号公告）

| 项目 | 内容 |
|------|------|
| **中文名称** | 蛹虫草 |
| **拉丁名称** | *Cordyceps militaris* |
| **基本信息** | 来源：人工培养的蛹虫草子实体。种属：子囊菌亚纲、麦角菌科、虫草属。 |
| **生产工艺简述** | 接种蛹虫草菌种到培养基上进行人工培养，采收蛹虫草子实体，经烘干等步骤而制成。 |
| **不适宜人群** | 婴幼儿、儿童、食用真菌过敏者 |
| **标签标注要求** | 标签、说明书中应当标注不适宜人群。 |
| **其他需要说明的情况** | 此数据更新了2009年第3号公告的数据。食品安全指标参照我国现行食品安全国家标准中食用菌类的规定执行（由2023年第4号公告修订）。 |

### 6. 植物甾烷醇酯（扩大范围，更新2008年第20号公告）

| 项目 | 内容 |
|------|------|
| **中文名称** | 植物甾烷醇酯 |
| **英文名称** | Plant stanol ester |
| **基本信息** | 来源：植物油或塔罗油提取的甾醇和植物油制取的脂肪酸甲酯。分子式：C₄₇H₈₄O₂，分子量：681.2 |
| **生产工艺简述** | 植物油甾醇经饱和工艺转化为植物甾烷醇，植物甾烷醇与脂肪酸甲酯进行酯化反应生成植物甾烷醇酯后再进行清洗、漂白和脱臭处理生产而成。 |
| **食用量** | ＜5克/天 |
| **不适宜人群** | 孕妇和5岁以下儿童 |
| **标签标注要求** | 标签、说明书中应当标注不适宜人群。 |
| **质量要求** | |
| 　植物甾烷醇 | ≥55% |
| 　植物甾醇 | ≤5% |
| 　游离脂肪酸 | ≤0.1% |
| 　干燥失重 | ≤0.1% |
| 　铅(Pb) | ≤0.1 mg/kg（2023年第4号增补） |
| 　总砷(As) | ≤0.1 mg/kg（2023年第4号增补） |
| 　苯并[α]芘 | ≤10 μg/kg（2023年第4号增补） |
| **其他需要说明的情况** | 此数据更新并取代了2008年第20号公告的数据。 |
