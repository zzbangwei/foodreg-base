# 关于弯曲乳杆菌等24种"三新食品"的公告（2019年第2号）

2019年 第2号

根据《食品安全法》规定，审评机构组织专家对弯曲乳杆菌等3种新食品原料、硫酸镁等15种食品相关产品新品种、L-γ-谷氨酰-L-缬氨酰-甘氨酸等6种食品添加剂新品种的安全性评估材料审查并通过。

特此公告。

## 新食品原料部分（共3种）

### 一、弯曲乳杆菌

| 项目 | 内容 |
|------|------|
| 中文名称 | 弯曲乳杆菌 |
| 拉丁名称 | Lactobacillus curvatus |
| **其他需要说明的情况** | 1. 批准为可食用菌种，使用范围不包括婴幼儿食品。2. 食品安全指标应符合我国相关标准。 |

### 二、明日叶

| 项目 | 内容 |
|------|------|
| 中文名称 | 明日叶 |
| 英文名称 | Ashitaba |
| 基本信息 | 来源：伞形科明日叶（Angelica keiskei Koidzumi） |
| 生产工艺简述 | 以明日叶的茎和叶为原料，经筛选、清洗、烘干等工艺制成。 |
| 推荐食用量 | 鲜品≤50克/天，干品≤5克/天 |
| **其他需要说明的情况** | 1. 婴幼儿、孕妇及哺乳期妇女不宜食用，标签及说明书中应当标注不适宜人群。2. 食品安全指标应符合我国相关标准。 |

### 三、枇杷花

| 项目 | 内容 |
|------|------|
| 中文名称 | 枇杷花 |
| 英文名称 | Loquat flower |
| 基本信息 | 来源：蔷薇科枇杷（Eriobotrya japonica (Thunb.) Lindl.）的花 |
| 生产工艺简述 | 以枇杷花为原料，经去梗、清洗、烘干等工艺制成。 |
| 推荐食用量 | 干品≤8克/天 |
| **其他需要说明的情况** | 1. 婴幼儿、孕妇及哺乳期妇女不宜食用。2. 食品安全指标应符合我国相关标准。 |

> **注**：本公告同时含15种食品相关产品新品种和6种食品添加剂新品种，此处仅提取了新食品原料部分。
